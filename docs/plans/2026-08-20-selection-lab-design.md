# Selection Lab · 筛选练习实验室（设计稿，2026-08-20，等 Andy 批）

*Andy："前期进行大量筛选练习，建立自我学习数据库，每个决策过程的原因要能够被记录。数据海量还没想好怎么处理，是否可以从一个特定 setup 开始。先设计，不做大，做精细，解决特定问题。"*

## 解决的特定问题（一句话）

**统计已证：回踩买入的优势只存在于"对的票"上（领头股 +7.5，全池 −4.5）——但"对的票"的判别器在 Andy 脑子里，不在任何字段里。** 本实验室的唯一目标：把这个判别器逐步显式化、可测化。

## 一个 setup 起步（推荐：新高后回踩）

选它的三个理由：①Andy 点名的原型（"特别是出新 52wh 后回撤的"）；②日频 5–15 个候选，够"大量练习"；③正是统计上"需要人来分辨"的那个 setup——第一波/EP 规则已经够硬，不缺人判。**其它 setup 一律不进 v1。**

## 两种练习模式（解决"海量"与"等待"）

| 模式 | 做法 | 量 | 反馈延迟 |
|---|---|---|---|
| **历史盲测**（主力，占 80%） | 从 git 的 88 个历史快照里抽一天，重建当日该 setup 的候选卡（图截到当日，**未来遮住**）；Andy 逐张判"买/看/否 + 一句理由"；判完立刻揭盅（前瞻 5/10/20 日已是历史，即时对答案） | 一次 10 张，15 分钟；档案够抽几百张 | **零**——这是"大量练习"的唯一解 |
| 实盘日题（辅助，占 20%） | 每晚 cron 出当日候选，Andy 有空就判；20 日后自动对账 | 5–15 张/日 | 20 日 |

## 每个决策记什么（`data/research/selection_lab/decisions.csv`）

`date_practiced, mode(blind|live), asof_date, setup, ticker, andy_verdict(买/看/否), andy_reason(原话), tags(我从原话打的标签：extended/主题弱/量不对/图脏/位置好/…), claude_pred(我预判你会怎么判), claude_reason, readings(全套当日字段), fwd5/10/20(盲测即填,实盘后补)`

**关键设计——我先押注**：每张卡我先写死自己的预判（你会买还是否，为什么），再看你的。三个可算的分随之而来：
1. **一致率**（我预判你 = 你实判）——衡量我学你学得多快；
2. **你的判别力**（你"买"组 vs "否"组的前瞻差）——衡量你的直觉里有多少可测优势；
3. **标签优势表**（"因太 extended 而否"的组 vs 留下组）——你的每一类理由单独验，有优势的理由沉淀成规则、进六席/面板，没有的就知道那是噪音。

## 节奏与出口

- 一轮 = 10 张盲测卡（chat artifact，标准卡样式），你判完我当场揭盅 + 落账。想练就说"出题"。
- 每攒 100 个决策出一份小结（一致率、判别力、标签表）；**300 个决策**后第一次正式回答"Andy 的判别器里哪几条可以写成代码"。
- 不建网页、不建新面板、不动六席——实验室归实验室，产品归产品；从实验室毕业的规则才进产品。

## 明确不做的

多 setup 并行；自动改规则；任何"AI 替你判"的功能——我的预判只用来测我自己的收敛，永远显示在你的判之后。

## 五、录屏工作流（Andy 08-20 追加：口述理由 + 录屏，既是语料也是内容）

**练习时的分工变化**：你判卡时**只打字最简判定**（"买/看/否"三个字甚至只打序号），理由**口述**进录屏——练习提速，理由反而更丰富（口语里的犹豫、比较、否决顺序都是标注）。

流程：
1. 你录屏（画面 = 卡片 artifact，声音 = 口述）；文件放 `data/research/selection_lab/recordings/`（**gitignored**，命名 `YYYY-MM-DD_r<轮号>.mp4`），录完告诉我。
2. 我：转写（video-subtitles 管线）→ 按 ticker/时间戳把口述理由对齐到 `decisions.csv` 的每个决策（替换/补充打字理由）→ 打标签。
3. **剪辑片单**：每轮出一份 clip sheet（时间码 + 建议切点 + 一句话字幕），选段标准照品牌规矩（BUILD 桶：落在数字、过去式、不预告）；**判对的和判错的都剪**——"我看走眼了"正是刊物的声音。发布节奏归内容台（content routine），我只备料。
4. 隐私闸：剪辑候选里出现仓位/金额一律打码标记，片单上标 ⚠ 由你终审。

**这个格式的传播价值**（为什么它天生能剪）：盲测 = 悬念（他会怎么判）→ 判断（口述理由）→ 揭盅（历史答案当场出）——一张卡就是一支完整的 15–60 秒竖屏，不需要任何后期叙事。
