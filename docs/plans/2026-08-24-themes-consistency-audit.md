# Themes 页一致性体检（2026-08-24，前端 UI 线）

在 `#/groups` 实机上跑探针量的，不是读源码猜的。结论按「要不要动、动了会不会破坏别的东西」排序。

分档：🔴 语义冲突（读者会读错）· 🟡 体系不齐（不会读错但看得出是两个人做的）· ⚪️ 记账（知道就行）

---

## 🔴 1. slot-1 的「蓝」在两个主题下都等于正文墨色

选中一个主题时，它在四态场上的点和标签换成 `--color-slot-1`。实测：

| | slot-1 | 正文墨 `--color-text` | 对比度 | RGB 距离 |
|---|---|---|---|---|
| 暗色 | `#e0e9f2` | `#e6e5e5` | **1.02** | 15 |
| 亮色 | `#12212e` | `#1c1917` | **1.07** | 26 |

`useThemeCompare.js:16` 的注释写的是「nameable in speech: 『the blue one』」「三个色相约 120° 分开」「Okabe-Ito adjacent，能扛住色觉异常」。**实际读者看到的是一个白色（暗色下）或黑色（亮色下）的点**，说「那个蓝的」指不出来。

它现在是靠**亮度抬升**在工作的：未选中的名字是 `--color-text-secondary`（`#b7b6b5`），选中抬到 `#e0e9f2`，二者 1.65 —— 抬升有效，色相无效。

⚠️ 这条踩的是仓库里已经记过的坑：`index.css:118` 那段自己写着三个 slot **彼此**量过（12/26/40 L\*）、**对卡底**量过（11.8/7.9/4.9）——唯独没量 slot 对**页面自己的墨**。同一支 token 两个职责，量过其中一个不等于另一个也对。

**可选处理**（都不难，选一个）：
1. slot-1 换成真的能认出是蓝的值（暗色下往 `--color-took` 方向走，别停在近白）；
2. 或者认了——把注释里「the blue one」改成「the bright one」，并给选中态加第二通道（现在轨迹线有 dash，场上的点没有）。

## 🔴 2. slot-2 / slot-3 是绿 + 橙，正好是色觉异常最容易混的一对

注释说三色是「blue / orange / purple」，实际 token 是蓝 / **绿** / 橙。绿橙对比度 1.6（暗）/ 1.66（亮），亮度分得开，但**红绿色觉异常下这两个色相互相塌陷**——而注释给的理由恰恰是「survive the common colour-vision deficiencies」。要么把 slot-2 换回紫，要么把注释里的理由删掉别自证。

## 🔴 3. 我的彗尾预览和这页现行的颜色语法互相打架 —— 需要你拍板

- 现行 Themes 场上白纸黑字写着：**「colour only says which theme you picked — it never grades one」**。
- 我做的轨迹预览里：**蓝 = 换到更强的态，红 = 换到更弱**。这就是在用颜色**评级**。

两个都自洽，但不能同页共存。两条路：
- **A（保现行）**：轨迹图也只用身份色，强弱交给位置（象限本来就说了强弱）。代价：一眼看不出谁升谁降。
- **B（改现行）**：颜色升级为「态的变化」，身份改用 dash / 标签。代价：这页的「颜色不评级」这条规矩要作废，全页跟着改。

## 🟡 4. 全页英文，只有 PATH 一块是中文

统计：`RsPath.jsx` 190 个汉字，`groups/` 下另外 8 个组件 **0 个**。页面正文里中文只出现在 FIELD 块内那 64 个字符（"11/50 个交易日"、"一格 = 一个交易日当天发布的态…"）。这是我自己建的那块，孤岛是我造的。

## 🟡 5. 字号有 10 档，其中四档几乎挨着

实测正文字号：10 / 11 / 11.5 / 12 / 12.5 / 13 / 15 / 16 / 17 / 46。11 与 11.5、12 与 12.5 肉眼分不出差别，只是让维护的人多四个决策。✅ 好消息：**没有一处低于 10px 地板**。

## 🟡 6. 小数位不齐

全页 32 个百分数是 1 位小数，3 个是 2 位（`+2.37% / +0.15% / -0.19%`，都在 COMPARE 的每日速度里）。同一页两种精度。

## 🟡 7. 同一类控件两种实现

窗口切换、展开、Compare 卡都是真 `<button>`；RANK 的行是 `div[role="button"][tabindex="0"]`。键盘能用，但同一页两种写法。

## ⚪️ 8. 窗口开关（1W/1M/3M）只驱动一半的页面

实测：切到 3M 时**变**的是导语句和 COMPARE 块；**不变**的是 FIELD 与 PATH。FIELD 用整段散文说清了自己不跟（写得很好）；**PATH 没有说**——它只印了 `11/50 个交易日`，没印「本图读的是季度，不跟上面的开关」。加一句就齐了。

## ⚪️ 9. 已经合格、别动的部分

- 正负号**不用红绿**：全页 +/- 数字都是灰阶三档（`#e6e5e5 / #b7b6b5 / #979594`）——反多巴胺这条守住了。
- 分母都印在图上：`30 themes of 56 groups`、`11/50 个交易日`、`size = horizons led 0–5`。
- 四态定义在场上、导语、COMPARE 三处一致。
- 无一处字号低于 10px。

### 量法（可复跑）
浏览器控制台跑探针遍历 DOM 读 computed style（不是 grep 源码）：字号/颜色直方图、`+x.x%` 小数位统计、切窗口前后逐块 diff、点选前后各 SVG 的用色集合、token 两两对比度与 RGB 距离。
