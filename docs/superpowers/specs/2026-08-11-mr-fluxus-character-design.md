## 风格宪法（2026-08-13 晚 · Andy 口述定案，高于一切风格描述）

四个悬而未决的问题当晚全部拍板，两处修正 Claude 建的框架：

1. **线的性格：TE 式粗黑线。** 重、钝、有态度。大块死黑是主角，细线只做辅助。
   不做 Sempé 颤线、不做蚀刻（Andy 明确否，且六库锚点为零，已淘汰）、
   不做精致中性的 editorial 插画线。
2. **密度与完成度：满可以，精修不行。** 画面可以塞满；完成度要「糙而带劲」——
   笔触外露、飞白、过头的笔画都欢迎。**要能刺激到一点多巴胺**——酷、冲、有 punch。
   反多巴胺是信息设计的纪律（仪表盘层面），不是画面的死气。
   注：这与 Margiela 纸片族的极端克制**不同**——版式制度可以 Margiela，画面本身要有劲。
3. **色的制度（确认不变）：** 纸色底 + 墨 + 单点橙 #D1600F。画面再满，橙也只有一处。
4. **世界结构（确认）+ 猫的定位修正：** 现实层/脑内层不变。
   **猫是人性化的点，不是叙事引擎**——股票世界全是涨跌，生活里有只猫才是戳人的点。
   它出现、它可爱、它偶尔闯祸，但不承担连载戏份、不抢戏。
   （此条替代早前「猫有很多戏」的表述。）
5. **实体文化感是一个独立的喜欢机制。** Andy 喜欢黑胶片，原因是**文化血统 + 酷 + 实体**，
   不是 riso 印刷技法（riso 不立项）。这条通往 invitation 实物、特刊、周边——
   把画印在真东西上，比把画修得更细重要。

## 宪法附则 · 双声部与定位（2026-08-13 深夜）

**双声部**（Andy 认可「可以慢慢立起来」）：Fluxus 是一个品牌的两个声部——
**盾**（dashboard/网站：反多巴胺、信息转执行、冷静有格局）与
**矛**（MR. FLUXUS/营销：粗黑线、糙而带劲、每帧一击多巴胺）。
两声部共享三样而成一体：同一套材料（纸/墨/同 hex 的橙）、同一条单点纪律
（产品=唯一 accent 与一句话结论；画面=一根橙线一张脸一只猫）、同一个世界观（测量、deadpan、不庆祝）。
护栏：同料不同音量 / 角色永不挨着测量 / 信是过渡件（冷正文+带劲头图+暖 P.S.）。

**定位坐标（CDG > Margiela，Andy 口述）**：对峙的酷（作者不说话、作品挑衅）优于退场的酷（匿名消失）。
CDG 机关=一个颜色+剪裁颠覆一切=Fluxus 的墨+单点橙+构图。radical transparency 使 Margiela 路线不可用。
三线结构：主线=dashboard · PLAY 线=MR. FLUXUS+猫 · DSM=invitation 实物/周边。
「没有强有力的声音」的解法不是音量,是 **collection 节奏**：一期一个论点,成集发布,拒绝解释。
定位候选句（放着长,未定案）：**「CDG 的纪律,穿在一个露脸的人身上」**。
完整拆解见素材库 `Taste_Library/2026-08-13_cdg_vs_margiela/NOTES.md`。

## ⭐ 核心地基 · 杜尚《3 Standard Stoppages》（2026-08-13 深夜 Andy 口述,当夜确认:「精华,精辟。无比记住这是核心地基」）

Andy 学数学出身；他入当代艺术的门就是这件作品：一米线掉落三次，三个形状，同一个长度——
科学的「真理唯一」与艺术的「不必唯一」之间的微妙差别。

地基已确认;三个候选产出仍待裁：

**发现**
1. 血脉闭环：杜尚→Cage→激浪派→白南准。Stoppages 与 TV Buddha 是同一谱系的头与尾,
   公司名 Fluxus 即 Andy 的审美家谱
2. Stoppages = 交易系统本体:每笔交易是一次掉落——长度(1R)自定,形状(结果)偶然;
   39.9% WR 的含义=只保证每根线一米。盖 NO 章的档案=杜尚的「罐装偶然」
3. 橙线已是掉落机:规则固定(一笔到底),形状每张不同(市场给的)。**每一张画=一次掉落**

**候选产出**
1. 「每日掉落」生成式标记:一米线每期掉落一次,形状取当天真实价格路径,`1m · drop #047`
2. 尺子实物升级:**一边直(标准刻度)一边弯(某次掉落的曲线刻度)**——杜尚木模板的可用品版
3. 宣言海报副标:"Same length, different shapes."

双声部的哲学地基由此补全:**盾=公理(唯一真理的度量),矛=掉落(偶然赋形)。**

## 道具新增 · 尺子（2026-08-13 深夜，Andy 由那句话的画面感触发）

**「拿尺子丈量一切的发言人」**（"I don't have opinions. I have measurements." 的画面版）。
考古依据：电脑之前的图表派交易员就用尺子在打印走势图上画趋势线——尺子是这门手艺最老的测量工具，
不是怀旧摆件。它是横跨两层世界的物件（现实层 2026 电脑 / 脑内层 1970 仪表）。

三个落位：
1. **宣言海报（待产,第一优先）**：大片纸色,一根巨大橙色走势线横过,极小的 MR. FLUXUS
   站在梯子上举木折尺贴线丈量,deadpan。手写 "I don't have opinions. I have measurements."
2. **invitation 实物第一号候选**：真木尺,丝印 FLUXUS 登记小字+那句话。
   文化血统+酷+实体三机制全中,成本低易寄送
3. **道具系统入列**：NO 章 / 透明笔 / 凉茶 / 木折尺——「测量的文具」全家福;
   动画里「量橙线」的动作 = 「测量是我的武器」的动作版

## 品牌书 v0 · 细节缺口清单与页序（2026-08-13 深夜立项）

Andy：五层塔（定位/结构/宪法/机关/角色）要深挖成「独一无二、浑然天成、有具体细节」的形象；
他对细节仍充满疑问——**因为还没看到**。裁决：深挖方式=样张不是讨论，
做一本品牌书 v0（样张集），每页一个细节决定 × 2-3 变体，用眼睛裁。

**细节缺口（按五层归位）**
- 定位/结构：FLUXUS 字标从未设计过（全系统最大的洞）；字体制度（登记小字/标题/手写/中文）；
  两声部在网页上的交接样式
- 宪法：粗黑线的精确档位（需要「线的样卡」）；#D1600F 跨媒介校准（屏/印刷/丝印）
- 机关：「每日掉落」生成规则（路径取段/长度/线宽/编号格式）——可代码化当场演示；
  尺子双面刻度工艺
- 角色：**企鹅零设计**（脑内世界主角）；猫定稿；散户/Algo Monkey 长相；
  场景模板规格（信头图/X 卡/海报的尺寸与网格）

**页序（按依赖）**
1. 字体与字标页——3 个字标方向 × 字体制度 × 中英混排样张（一切排版的地基）
2. 「每日掉落」演示页——真实 SPX 路径生成 5 个掉落标记，`1m · drop #001` 起编
3. 宣言海报——五层第一次同框（粗黑线+橙色掉落线+尺子+那句话+登记小字）
4. 之后：线的样卡 / 企鹅设计 / 场景模板 / 声部交接样式（顺序由前三页的结果定）

## 修订记录 · 2026-08-13（出图实战后，与 Andy 逐条对齐）

**这一节优先级高于下文任何冲突条款。** 一整天的出图把几条设想证伪了，改动如下：

| 项 | 08-11 初稿 | 08-13 定案 |
|---|---|---|
| 表情系统 | 六模式（DEADPAN/ANNOYED/LOCKED IN/DEFENSE/PANIC/ASLEEP） | **退役。只有一张脸。** 见下 |
| 那张脸 | —— | **忙但专注**：头向下微倾、**眼睛睁开有瞳孔**、目光落在桌面的活儿上（不看观众、不看屏幕），眉头不皱、嘴一条平线。定稿见 `explorations/2026-08-11_mr_fluxus/face_study_focused.png` 下排第一格 |
| 年龄体型 | 中年、微胖 | **35 岁**，身形结实不走样，圆脸但下颌线在；**fashionable / artistic**——「邋遢但帅气藏不住」（Anderson＝基努·里维斯，不是发福上班族）。帽子和圆镜读作**造型选择**，衬衫是艺术生的松垮不是上班族的邋遢，微胡茬、头发略长出帽檐 |
| 猫 | 一只 plump indifferent cat | **一只美国短毛猫**（银虎斑：粗黑漩涡纹、条纹四肢与尾、额头 M 纹）。**全画只许一只**——模型反复偷加第二只，出图时必须逐张数 |
| 屏幕内容 | 手绘简化的图表 | **不画走势**。改为数据矩阵（密排小数字）、散点图、条码状 tick 列、热力方格——「一直在变的数据」，把「唯一的曲线」让给茶烟 |
| 单点橙的落点 | 盖下去的 NO 章 | **茶杯升起的一根线**：从杯口起是烟，过头顶变成起伏的走势，飘出画外。**必须一笔到底全橙、不许中途转黑**，且贴着杯和头升起（飘远就散成两样东西）。它是全画唯一的颜色、唯一的曲线、唯一在动的东西——而他没看它 |
| 眼镜 | 金丝圆框 | 保持金框，但要**浅黄铜色、细**，明确比烧橙冷；金与橙是邻色，糊在一起会毁掉单点橙。若再打架就退回纯墨线 |
| 比例 | Sempé 式「人占八分之一」 | **接受人占约四分之一**。Gemini 在「保住人脸」和「拉远镜头」之间有固有取舍，八分之一要不到。极端比例留给特定远景画面（如「打鼾夜」）。**反差靠房间大，不靠家具变形**——上一轮把显示器画成超现实巨物是错的 |
| 与 TE 的关系 | 参照 MR. UPDATE | **不照抄**。查证结论：TE 官网上 Mr. Update **只有一张脸、只有一个场景**，变化全靠情境。我们反过来——**脸固定，场景一直变，猫有很多戏**。可偷的是技术：大黑块 vs 细抓痕的对比、唯一的橙是一根线不是一块面 |
| 画风 | 手绘墨线 | 同，但**偏墨线漫画而非插画**：笔画更少更狠、粗细变化明显、脸和衣服不做柔和调子，阴影只用粗排线或整块死黑，留白见纸 |

## 〇、这是什么

Fluxus 品牌的**视觉代言角色**:MR. FLUXUS,一个漫画化的交易者(本人)。
用在 Substack(每期信开头)、网页(仪表盘最底部)、X(独立发,配当天测量行)、课程(章节开场)。
远期扩展为带音效与动画的网页(参考 TE reel 的节奏)。

参照系是 teenage engineering 首页的《DAILY LIFE OF MR. UPDATE》:
冷系统 + 暖角色,把品牌真正在做的事拟人化,幽默来自真实。
**画风走 MR. UPDATE 式的漫画网格**(多格分镜),单格场景用横幅。

v1 简报(2026-08 初)已定的「他是谁、出现在哪、三条不许」大体继承,
本稿在其上做了四个决定:**真人化、去英雄化、双层世界、动物 cast 进画面。**

## 一、角色 — MR. FLUXUS

### 1.1 长相:漫画化的本人(参考照片)

| 签名件 | 说明 |
|---|---|
| **黑色针织渔夫帽** | 第一识别项,剪影层面即可认出 |
| **金丝圆框眼镜** | 第二识别项 |
| **格子衬衫** | 微皱。居家、反华尔街 |
| **圆脸 + deadpan** | 参考照片里的表情就是标准像:不悲不喜不笑,基线略带不耐烦 |
| **一支透明圆珠笔** | 固定手持道具(复盘写一行字的那支) |

命名锁定 **MR. FLUXUS**,与 MR. UPDATE 命名结构对仗(MR. + 品牌真正在做的事)。
参考照片由 Andy 提供,存 `Fluxus_Marketing_Visual_Design/`(素材库,不进 git)。

### 1.2 气质:grumpy 的止损文员(不是冷静狙击手)

**反大师是位置,去英雄化是本稿的核心修订。**
「静静等待、一击必中」是成功学大师人设,与 39.9% 的真实胜率、
与《I lose more than I win》的底色相拧,弃用。取而代之:

- **他的日常工作看起来就是「亏钱和盖章」。** 一天的产出:几张被止损的单子,
  每张面无表情盖上 **NO** 章归档。桌上那摞纸越堆越高。
  胜率四成、输的次数比赢的多——写在画面里,不藏。这是 radical transparency 的图像版
- **Grumpy。** MR. UPDATE 的牌子是 "BUSY — MEET ONLY BETWEEN 10:30 AND HALF PAST TEN",
  MR. FLUXUS 的牌子是 **"NOT FINANCIAL ADVICE — 别问我你的股票"**。
  社群戏的核心冲突:所有人都想让他荐股,他烦。回消息永远一个词。被 @ 一百次,回一个 "no"
- **邋遢(Anderson 态)。** 衬衫皱、帽子歪、茶杯没洗、桌面是纸的地质层。
  一个看起来完全不像会赢的人
- **那个抽屉。** 从 H1 行为审计搬进来的真实弱点(对破碎论点的反复进攻,BABA 5x):
  一个贴着标签的抽屉,他明知道不该开,画面里手又伸过去了。
  角色最真实的裂缝——越扎心越能共情,保留

### 1.3 内核:外静内忙

表面是一个在等的人,手停着;脑子里飞快地读数据、处理数据。
最终动作小到可笑:按一下鼠标。真忙(手忙脚乱贴便签敲键盘)是他的反面案例,永不这样画。

## 二、双层世界 — Anderson / Neo 结构

角色的戏剧机关**不在脸上,在层与层之间**。参照《黑客帝国》:
现实层的 Thomas Anderson 是个邋遢程序员,进入 Matrix 才判若两人。

| 层 | 他是谁 | 画面 |
|---|---|---|
| **现实层** | 邋遢的止损文员 | 他一天里最重要的时刻,和检查邮件在画面上毫无区别:同一个坐姿、同一张脸,食指按了一下鼠标。没有前倾、没有发光、没有音乐。旁边的猫都没醒 |
| **脑内层** | **企鹅化身**(First Penguin) | 同一秒,企鹅从冰崖跃入水中。测量完毕、毫不犹豫、干净利落。所有的锋利只存在于这一层 |

**两层成对出现才成立**:单独看现实层是个无聊的点击,单独看脑内层是张漂亮的跳水图,
拼在一起才是品牌的全部论点——**它看起来像无事发生,其实是量完之后的纵身一跃。**

规则:

- 企鹅是他的**场上化身**(游戏玩家与操作角色的关系),他本人永远不进脑内世界
- 禁止一切「变身」语法:瞳孔特效、气场、发光、慢镜英雄感——全在否定清单里

## 三、配角 — 猫

真实存在的、常出没他办公室旁的猫。两个戏份:

1. **键盘旁睡觉**(大多数日子)
2. **踩键盘替他下单**(偶尔捣乱)

它是家里的 Market God 化身——不可预测、不可谈判、你还得爱它。
对仗 TE 画面里那只玩电脑的狗。

## 四、世界地图 — 四个固定景,各住一个角色

TE 的设置极简:自己的办公室、同事的办公室、若干外部超现实。我们同构:

| # | 景 | 常驻角色 | 戏 |
|---|---|---|---|
| 1 | **交易室**(真实的家:多屏 + 蕾丝窗帘 + 茶 + 猫) | MR. FLUXUS + 猫 | 主舞台。等待/复盘/反高潮点击/睡觉打鼾市场翻天/猫下单 |
| 2 | **华尔街机房** | Algo Monkeys | 一排排终端前面无表情的猴子,被自己的风控代码逼着卖弱买强 |
| 3 | **散户的厕所隔间** | 一个固定散户形象(the Herd 代表) | 上班躲进隔间用手机追涨,群聊在响 |
| 4 | **脑内世界**(超现实层) | 企鹅化身 + Market God | 从屏幕里漫出来;TE 式 1970 模拟仪表机器;测水温、跳水、与庄家对坐 |

**多空博弈不画牛熊**(否定清单原条款保留)。
那是一场没人离开座位的战争:散户用手机,机构用终端,全员在屏幕前,
输赢差别只在谁量过。「牛熊大战」的戏剧感由自家 cast 演,不借华尔街旧符号。

## 五、脑内世界的引用库 — 激浪派,不是华尔街

品牌名 Fluxus 即出处。脑内世界的超现实引用**统一取自 Fluxus/激浪派媒体艺术**,
给看得懂的人留暗号:

- **固定装置位:「TV BUDDHA 位(复盘位)」** — 借白南准《TV Buddha》的闭路自观结构:
  **一只企鹅面对一台 1970 年代 CRT 电视,屏幕里播的是这只企鹅自己。**
  用于复盘/自我审计主题(月度 review、行为诊断、NULL 结果归档)。
  艺术圈认出白南准,交易员认出复盘,两层都通
- 白南准的 CRT、闭路循环、堆叠电视墙均可入画;
  脑内的 1970 模拟仪表与 CRT 美学同年代同硬件,天然咬合
- **红线:MR. FLUXUS 真身不摆佛像坐姿**——「禅意大师」否定条款照旧,替身戏全部由企鹅演

## 六、画法规格(继承 Prompt Pack v1,两处更新)

继承不变:

```
线      手感墨线,黑色,粗细有变化;不要矢量等宽线
阴影    交叉排线(hatching),不用灰色块
比例    轻微夸张,表情 deadpan 基线(本稿下调为「略带不耐烦」)
文字    画内文字全手写;这是画面里唯一允许的手写
色      黑白为主。橙色 #D1600F 全画面一处,不超过一处
底      纸色 #F4F3F0,不出血、不加框、不加阴影、不加纹理
构图    Sempé 式「极小的人 + 极大的环境」(场景格);他要小,环境要大
```

更新两处:

1. **环境**:现实层画真实的家(含现代屏幕,屏上图表手绘墨线简化,不写实);
   模拟仪表只住在脑内世界。v1 的「纯 1970 控制室、不要屏幕」条款仅对脑内层继续有效
2. **叙事格式**:多格漫画网格(MR. UPDATE 式)为主;单格场景仍用 16:9 横幅

否定清单全部保留:Corporate Memphis / 企业吉祥物 / 牛熊箭头钞票 / 吊带裤交易员 /
僧袍蒲团山顶 / 游艇雪茄 / 赛博朋克霓虹 HUD / 3D 渲染渐变玻璃 / 动漫大眼 / AI 通用长相。
新增两条:**变身特效语法** / **英雄慢镜**。
