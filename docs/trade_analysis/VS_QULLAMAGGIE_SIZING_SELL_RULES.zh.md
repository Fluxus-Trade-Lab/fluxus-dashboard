# 对表 Qullamaggie:仓位与卖法 · 文章素材

来源:@Muninn 两篇实证(2026-08-31 仓位篇,基于 500+ 场直播;2026-08-03 卖法篇,基于 829 笔实盘)

## 核心发现(文章主线候选)

**① 同一个人、同一批交易、两个 risk/trade 数字 —— 度量口径的故事**

| 口径 | 我的 risk/trade | 读法 |
|---|---|---|
| ÷ 起始本金 $1M(此前审计口径) | 均值 **0.52%** | "超标 2 倍" |
| ÷ **入场当日权益**(Muninn/Q 的口径) | 均值 **0.37% · 中位 0.30%** | **正好在 Q 的 0.2–0.5% 带内** |

账户从 $1M 涨到 $2.15M,同样的美元风险,分母变了结论就变。**之前"你押大了 2 倍"的诊断,一半是分母造成的。** 真正超带(>0.5%)的只有 19% 的交易;>1% 的只有 7 笔(最大 OKLO 8.1%,+0.0R —— 押最大的那笔白干)。

**② 趋同进化:没抄过他,数字却几乎一样**

| 指标 | Qullamaggie(Muninn 实测) | 我(373 笔实测) |
|---|---|---|
| risk/trade | 0.2–0.5%(自述+实测) | 中位 **0.30%** ✓ |
| 单笔仓位中位 | 7.4%(多仓日) | **7.6%** ✓ |
| 单仓天花板 | 20–25%,>25% 仅占 7% | 最大 22.4%,>20% 仅 3/373 ✓ |
| 同时名字数中位 | **8** | **8** ✓ |
| 账户周转 | 40×/8 个月 | 28×/8 个月(同量级) |
| 组合形态 | 少数核心 + 一堆 partial 残段 | 当前 9 仓里 8 笔是部分减仓后的残段 ✓ |
| 止损距离中位 | 突破 2.44% / EP 3.85% | **4.15%**(偏 EP/高 ADR 打法,自洽) |
| Top-10 集中度 | Flanders: top10=全年 | top10 = 156R/339R = **46%** |

**③ 真正的分歧点(文章的"但是")**

- **止损管理**:Q 卖了一部分后移保本、10 日线跟踪;我 373 笔 `Stop Price` 从未更新(记录习惯)→ 浮盈裸奔,真实敞口峰值上界 30%。Muninn 数据反而支持"别早移保本"(满仓 day3 移保本净 −69R),我误打误撞站在对的一边——**但代价是没有任何浮盈保护,−17.9% 回撤由此而来**。
- **Exposure tempo**:Q "从空仓到满杠杆要几周不是几天";我 7/23 空仓 → 8/4 已 52%(8 个交易日)。他的准绳是"先看到已有仓位赚钱再加"——和我们审计的 corr(投入,市场分)=0.44 同步反应一致,但速度快于他的纪律。
- **过热环境下手太多**:47% 交易开在 Extended、质量最差(35.9% 胜率)——Q 的对应规矩是"30 个仓位=市场该歇了"的自嘲仪表。

## 卖法对照(Muninn 卖法篇 vs 我们的审计)

| 维度 | Muninn/Q 结论 | 我们 |
|---|---|---|
| 往强势卖 | 买的是平滑曲线+胜率,付的是均笔利润(-25%) | 99% 的分批盈利单往强势减 ✓(我们天然在这一侧) |

## 文章可用的钩子

1. **"我被自己的分母骗了"** —— 0.52% vs 0.30%,同一批交易;所有引用 sizing 规则的人都该先问"占什么的百分比"。
2. **"没抄他,但账本长得一样"** —— 8 个名字、7.6% 中位仓、每周一转:独立收敛=这些数字可能是这种打法的物理常数,不是谁的发明。
3. **"我在他最强调的地方最弱"** —— 他的核心是卖出后的止损纪律与 exposure tempo;我 373 笔没动过一次止损、8 天从空仓到半仓。
4. Kevin Davey 检验:每条结论都有笔数和反事实,不是"周一别交易"。
