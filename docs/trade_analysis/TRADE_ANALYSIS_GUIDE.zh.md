# 交易数据分析 · 教学

怎么把一份交易流水，变成能改进下一笔决策的东西。

分两层读：
- **入门篇** —— 第一次做复盘。不需要写代码，只要有完整的交易记录。
- **进阶篇** —— 已经会看胜率盈亏比了，想知道那些数字什么时候会骗你。

配套：[`TRADE_ANALYSIS_PROMPTS.zh.md`](./TRADE_ANALYSIS_PROMPTS.zh.md)（复制即用的 prompt）

# 入门篇

## 一、先想清楚：复盘要回答什么

大多数人的复盘停在"做了一堆图"。真正有用的复盘回答**三层问题**，而且每层都要落到"下次怎么办"：

| 层 | 问题 | 例子 |
|---|---|---|
| **描述** | 发生了什么 | 胜率 39.9%、盈亏比 3.40×、期望 +0.88R |
| **诊断** | 为什么 | 亏损主因不是抄底，是"给失败的加仓上了重仓" |
| **处方** | 该怎么做 | 改成等风险，同样这些交易多赚 67% |

**只有第三层能改变你明天的下单。** 前两层是为它服务的。

## 二、数据：没有止损就没有一切

导出 CSV，每笔至少要有：

```
标的 · 方向 · 进场日 · 进场价 · 数量 · 初始止损 · 每次减仓的(价/量/日期)
```

**初始止损是整套分析的地基。** 没有它，你只能算"赚了多少钱"，算不出"这笔冒了多少风险换来的"——而后者才是可比较的东西。

> ⚠ **两个止损字段要分开**：`初始止损`（锁死、当 R 的分母）和 `当前止损`（随移动更新）。
> 混成一个字段的后果：你一移止损，所有历史 R 被静默改写，而数字看起来依然正常。

## 三、R-multiple：把钱换成"份"

**R = 这笔盈亏 ÷ 这笔的初始风险**

初始风险 = |进场价 − 初始止损| × 数量。

举例：风险 $2,500 的单，赚了 $7,500 → **+3R**。

为什么必须这么算：$10,000 的仓位赚 $500 和 $100,000 的仓位赚 $500，**是完全不同的两件事**。换成 R 之后，大小不同的交易才能放进同一个分布里比较。

**这是 Van Tharp 整套体系的地基**：一个系统就是它的 R 分布。

## 四、必须认识的几个数

| 名字 | 怎么算 | 怎么读 |
|---|---|---|
| **期望值 Expectancy** | 平均每笔几个 R | **>0 才有正边缘**。+0.88R = 平均每冒 1 份风险赚 0.88 份 |
| **胜率 Win rate** | 赢的笔数 ÷ 总笔数 | **单独看没意义**，必须配盈亏比 |
| **盈亏比 Payoff** | 均盈R ÷ 均亏R | 39.9% 胜率 + 3.40× 盈亏比 = 健康的右尾打法 |
| **利润因子 PF** | 总盈利 ÷ 总亏损 | >1 才赚钱，>2 算好 |
| **最大回撤 MDD** | 从最高点跌下来多少 | **按百分比算，不是美元**（见下） |
| **夏普 Sharpe** | 超额收益 ÷ 波动率 | >1 好，>2 优秀。**把上涨波动也当风险罚**了 |
| **索提诺 Sortino** | 只罚下跌波动 | 对右尾打法比夏普公平 |
| **卡玛 Calmar** | 年化收益 ÷ 最大回撤 | "每承受 1% 回撤换来多少收益" |
| **SQN** | √min(N,100) × 期望R ÷ R标准差 | Van Tharp 的系统质量分，见进阶篇 |

## 五、三个新手最容易搞错的地方

**① 回撤要按百分比选，不是按美元**
账户从 $1M 涨到 $2M 的过程中：早期跌 $200k 是 −20%，后期跌 $220k 只有 −11%。**按美元找最大值，会选中后面那个，漏掉真正更痛的前面那个。**（我们真的犯过这个错。）

**② 未平仓的要盯市（MTM）**
只算已平仓 = 假装浮亏不存在。真实的权益曲线必须把未平仓按当日收盘价估值，回撤才是真的。

**③ 月度回报要复利，不要除以固定本金**
`本月末权益 ÷ 上月末权益 − 1`，而不是`本月已实现盈亏 ÷ 起始本金`。后者在账户增长后会严重失真，而且会和你的 dashboard 对不上。

# 进阶篇

## 六、SQN 与它的陷阱

```
SQN = √min(N, 100) × (平均R ÷ R的标准差)
```

分档：<1.6 差 · 1.6–2.0 低于平均 · 2.0–2.5 一般 · **2.5–3.0 良好** · 3.0–5.0 优秀 · 5.0–7.0 超凡 · ≥7.0 圣杯

**⚠ N 必须封顶在 100。** 这个封顶正是让分档校准的关键。用未封顶的 √N，一份 331 笔的记录会被抬到 4.99"优秀"——而真实值是 **2.74"良好"**。（我们也犯过。）

**SQN 高不等于赚得多。** 它奖励的是 R 流的**一致性**。想提高它：收紧亏损尾、让盈利跑——**不是加大下注**（加大下注同时放大分子分母，SQN 不变）。

## 七、Kelly 什么时候会骗你

Kelly 给出"增长最优"的下注比例。在真实交易里它几乎总是**过大**，原因有三：

1. **肥右尾**：几笔 +20R 会把 f\* 抬到荒谬的高度
2. **单边行情样本**：一段牛市里算出来的边缘不是稳态边缘
3. **边缘本身是估计**，不是已知常数

实例：我们的账户算出 **f\* = 15.9%/1R、组合杠杆 λ\* = 5.8×** ——照做等于自杀。

**所以：half-Kelly 或更小，而且要把 Kelly 当上限，不当目标。**
"下注双倍 Kelly，你会把全部收益抹掉"——这不是修辞，是数学。

## 八、仓位：最被低估的一门学问

复盘时问这三个问题（大多数人一个都没问过）：

**① 我的仓位大小和结果有关系吗？**
算 `corr(仓位%, R)`。我们的答案是 **−0.00**——押多押少，和最后赚几个 R 毫无关系。也就是说**仓位层没有贡献任何 alpha，只贡献了方差**。

**② 如果我每笔押一样重会怎样？**
同样的总风险预算重新平均分配，跑一遍反事实。我们的答案：**+66.7%**。这说明问题不在"押多少"的水平，在"押给谁"的分配。

**③ 我该持有几个仓位？**
```
N* = 总风险预算 ÷ 每笔风险，再取 min(N*, 经验死线)
```
例：3% 预算 ÷ 0.25% 每笔 = **12 个**。有意思的是这个算出来的数，常常和你凭经验定的"死线"重合——说明经验阈值不是玄学，是风险数学的影子。

**规则出数，死线封顶** —— 这是两层，不是二选一。

## 九、持仓热度：一个数不够，要三个

大多数人只看第一个，而它是最小的那个：

```
① 承诺风险 = Σ |进场−止损| × 未平数量 ÷ 当日权益
② 真实敞口 = Σ max(0,(现价−止损)·方向) × 未平数量 ÷ 当日权益
③ 浮盈回吐 = ② − ①
```

我们的实测：① 中位 3.53%，但 ② 中位 **7.45%**、峰值上界 **30%**。

**根因**：赢家一路涨、止损不动 → 从现价到止损的距离越拉越大 → **累积的浮盈全部裸奔**。

再配一个**集中度**（前 3 个名字占敞口比例）——峰值日我们是 54%，一个票就占 8.6%。

> 这解释了为什么最大回撤是 −17.9%：带着 30% 敞口进入一个月，那个数字是算得出来的，不是意外。

## 十、市场环境归因（如果你有市场状态数据）

把每笔按**入场当天**的市场状态分档，看各档的胜率/平均R。

我们发现：**最热的环境里下手最多（47% 的交易），却是质量最差的一档**（34.6% 胜率）；真正的甜区在"建设性"那一档。

三条必须一起说的警告：
1. 按**入场日**归档，但盈亏是后来实现的——在差环境入场、在上涨里了结的单会让差环境显得偏好
2. 样本通常只有一段行情
3. **市场状态分很可能对收益没有预测力**（我们验证过：558 个交易日，不预测下月收益），它更可能只对**回撤风险**有分离度

**所以它是风险预算的读数，不是择时信号。** 用它来决定"花多少风险"，不是"看多还是看空"。

## 十一、诚实的纪律

这几条比任何指标都重要：

- **敢报 NULL 结果。**"你担心的这个问题其实不存在"和发现一个问题一样有价值。我们查过"再攻击是不是最大漏点"——结果是**不是**（那些交易平均 +1.21R），真正的问题是给失败的那几次上了重仓。
- **每个数字标口径。** 同一个词（expectancy）在不同样本下不是同一个数。相邻两个面板显示不同的"期望值"而不标注，就是在制造混乱。
- **前瞻数字给区间，不给点估计。** 蒙特卡洛、Kelly、期望增长——都要带样本量和悲观情形。
- **分清市场风险和自己的行为问题。** 有时市场没问题，是你在那个环境里做得不好——处方完全不同。
- **两个 surface 要对账。** 报告和面板算同一个指标，必须用同一个公式。我们靠交叉对账，抓出过自己算错的 SQN。

## 附：术语速查

| 术语 | 一句话 |
|---|---|
| R-multiple | 盈亏 ÷ 初始风险，把钱换成"份" |
| Expectancy | 平均每笔几个 R，>0 才有边缘 |
| MTM | 盯市，未平仓按当日收盘价估值 |
| Drawdown | 从最高点跌下来多少，**按%不按$** |
| Profit Factor | 总盈利 ÷ 总亏损 |
| Sharpe / Sortino | 风险调整收益；后者只罚下跌波动 |
| Calmar | 年化收益 ÷ 最大回撤 |
| SQN | 系统质量分，N 封顶 100 |
| Kelly | 增长最优下注比例，实盘用 half 或更低 |
| Percent-risk | 每笔冒固定百分比的权益（Tharp 的专业标准） |
| Percent-volatility | 按 ATR 定量，让每笔的波动风险相等 |
| Anti-martingale | 赢加亏减（与"越亏越加"相反） |
| Position heat | 未平仓总风险占权益比例 |
