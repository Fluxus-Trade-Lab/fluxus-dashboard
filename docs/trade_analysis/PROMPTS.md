# 交易复盘 · 可执行 Prompts

把一份交易流水交给 AI，让它产出**能改进决策的结论**而不是一堆漂亮图表。
下面的 prompt 复制即用；每一条都写进了我们实际踩过坑之后学到的要求。

配套文档：[`TEACHING.md`](./TEACHING.md)（概念与方法）· [`../../PERFORMANCE_TRUTH.md`](../../PERFORMANCE_TRUTH.md)（本账户口径基准）

---

## 0 · 先准备数据

导出交易记录 CSV，每笔**至少**要有：

| 字段 | 为什么必须 |
|---|---|
| 标的 · 方向 · 进场日 · 进场价 · 数量 | 基本盘 |
| **初始止损** | **没有它就算不出 R** —— 整套分析的地基 |
| 每次减仓的 价 / 量 / 日期 | 没有分批就算不准盈亏和"往强势减仓"的行为 |

> ⚠ **初始止损（`Initial Stop`）和当前止损（`Stop Price`）必须是两个字段。**
> 前者锁死当 R 的分母、永不修改；后者随移动止损更新。混在一起 → 你一移止损，历史 R 就被静默改写。

## 1 · 全景复盘报告（带图）

```
这是我过去[时间段]的完整交易记录（CSV，含每笔的进场价／初始止损／数量／分批减仓的价·量·日期）。

请先把每笔换算成 R-multiple（R = 盈亏 ÷ (|进场−初始止损| × 数量)），然后生成一份带图的复盘报告：
① 盯市(MTM)权益曲线 + 回撤（未平仓按当日收盘价估值）
② 累计 R 曲线、每笔 R 柱状图、R 分布直方图
③ 月度/季度回报、按标的贡献（用 R，最好/最差并列）
④ 利润集中度（前 N 笔占多少利润）、回撤分布 + 最深 N 次、滚动盈亏比、连亏分析

要求：
- 回撤按**百分比**选最大值，不是按美元（账户增长时，后期的美元大跌占比反而更小，用美元会漏掉真正最深的那次）
- 月度回报用**权益曲线逐月复利**（endEq/prevEq − 1），不要用"已实现盈亏 ÷ 固定本金"
- 给具体数字，不要泛泛而谈
```

## 2 · 行为诊断（为什么赚 / 为什么亏）

```
基于我的交易记录做行为诊断，每个结论都要有数据支撑：
1) 我最大的几笔亏损有什么共同的技术/行为特征？（抄底？逆势？拿太久？对同一个 thesis 反复加仓？）
2) 最大的几笔盈利呢？
3) 回撤期我是加仓还是缩仓？
4) 我怎么减仓、怎么用止损？

要求：
- 别给"周一别交易"那种事后诸葛，要能落地的
- 如果某个我担心的问题其实不存在，直接说这是 NULL 结果，并用数据证明
- 区分"第一笔"和"后续加仓"的盈亏 —— 很多漏点藏在加仓里，不在首次入场
```

## 3 · 仓位审计（最深的一层）

```
审计我的仓位大小：
1) 每笔仓位（名义金额 ÷ 入场时权益 %）和它最终的 R 相关吗？算出相关系数并画出来。
2) 我真实的每笔风险（1R）占权益百分之几？和我的目标比。
3) 反事实：如果每笔改成**等风险**（同样的总风险预算重新分配），同样这些交易我会多赚/少赚多少？
4) 按 Van Tharp 的 percent-risk / percent-volatility 和 (half) Kelly，我该冒多少风险？
   给出 Kelly 数字，但要诚实说明它在牛市样本 / 肥尾上会失真。
5) 用蒙特卡洛重采样我的 R 分布，算不同风险% 下的：期末收益中位数、中位回撤、
   以及超过 X% 回撤的概率（Van Tharp 的 position-sizing-to-objectives）。

补充：持仓热度请分三个口径算，别只给一个：
① 承诺风险 = Σ |进场−止损| × 未平数量 ÷ 当日权益
② 真实敞口 = Σ max(0,(现价−止损)·方向) × 未平数量 ÷ 当日权益
③ 浮盈回吐 = ② − ①
并给出峰值日的集中度（前 3 个名字占敞口比例）。
```

## 4 · 反事实 + 一件最该改的事

```
基于以上分析：如果只改一件事，哪件对我的总收益/回撤影响最大？
用反事实量化（"改了这些交易，结果会从 X 变成 Y"）。
给我 2–3 条可执行建议，每条用这个格式："别再 X，改成 Y。"
```

## 5 · SQN · 系统质量分

```
算我的 SQN（System Quality Number = √min(N,100) × 期望值R ÷ R的标准差；**N 必须封顶在 100**）。
按 Van Tharp 分档告诉我属于哪一档（差/一般/良好/优秀/超凡），
以及要升一档该改进什么 —— 收紧亏损尾、让盈利跑，还是别加大下注。
```

## 6 · 市场环境归因（进阶，需要一条市场状态时间序列）

```
我有一条逐日的市场状态分（0–100）。请把每笔交易按**入场当天**的分数归档，
统计各档的：笔数 / 胜率 / 平均R / 总R / 总盈亏。

要求：
- 明确标注用的是哪一套分档口径和它的切点
- 说明可用的历史区间，不要默默截断
- 提醒我：按入场日归档意味着盈亏可能在之后的行情里实现（会让"差环境"看起来偏好）
- 如果这个分数对收益没有预测力（很常见），直说；它更可能只对**回撤风险**有分离度
```

---

## 通用要求（可以附在任何一条后面）

```
另外请遵守：
- 每个数字都标注**口径和样本**（例如"实时·本账 331 笔" vs "H1 审计快照"），
  同一个词在不同口径下不是同一个数
- 前瞻性的数字（蒙特卡洛/Kelly/期望增长）一律给**区间**不给点估计，并标样本量
- 敢报 NULL 结果。"你担心的这个问题其实不存在"和发现一个问题一样有价值
- 分清**相关**和**因果**，也分清**市场风险**和**我的行为问题**
```

---

## 附：这些要求是怎么来的

| 要求 | 来自哪个坑 |
|---|---|
| 回撤按百分比选 | 曾把 −17.9% 的真实最大回撤误报成 −11.1%（选了美元最大的那次） |
| 月度回报用复利 MTM | 报告和 dashboard 曾对不上，因为一个用复利一个用"已实现÷固定本金" |
| 初始止损与当前止损分开 | 移动止损会静默改写历史 R |
| 标注口径 | 同一页两个面板都写"expectancy"，其实是不同样本 |
| SQN 的 N 封顶 100 | 未封顶会把长记录抬进它没挣到的档位（4.99"优秀" vs 真实 2.74"良好"）|
| Kelly 要注明失真 | 单边牛市样本算出 f*=15.9%、λ*=5.8×，照做等于自杀 |
| 热度分三个口径 | 只看"承诺风险"是 3.5%，真实敞口其实 7.5%（峰值上界 30%）|
