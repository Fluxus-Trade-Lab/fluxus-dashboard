# 分栏设计 — TSF vs JB 对照 + 三个方案

*实测于 2026-08-03,读两家 publication 的原生 sections 配置。*

---

## 一、两家的做法完全相反

### TSF —— 用原生 Sections,4 个

```
主 feed          周末宏观大稿(Sentiment Cycle / Trend Fatigue / Panic Cycle)
├─ TSF - Trading Knowledge        22 篇教学档案
├─ Current Stock Trading Ideas    Focus Stocks 个股串烧
├─ The Momentum Leaders Portfolio ← founding 独占,栏目 = 付费闸
└─ Subscriber Testimonials        ← 社会证明做成栏目
```

**两个设计值得注意:**
- **`The Momentum Leaders Portfolio` 是 founding 专属栏** —— **栏目直接当作付费分层的闸门**。这是 Sections 最有价值的用法
- **`Subscriber Testimonials` 独立成栏** —— 把读者好评做成一个可浏览的档案,而不是散落在页面上

### JB —— **零个 Sections**

```
sections: []          ← 1,259 篇全在一个平铺的 feed 里
```

**他完全不用分栏。** 靠两样东西替代:
1. **标题约定** —— `7/31/26 Recap`(768 篇)· `Best Idea For The Week Ahead`(122 篇)
2. **导航栏钉 6 篇常青文** —— How Members Use This Data · My Process · Put Sale Win Rate · My First 100 Bagger …

**排第 3 的人,一个分栏都没有。**

## 二、Sections 的真实代价(决定你要不要用)

| | 好处 | 代价 |
|---|---|---|
| 读者可单独订阅某栏 | 精准 | **会拆散你的邮件列表** —— 有人退订某栏后,那栏的每篇触达都少一截 |
| 可按栏设置付费闸 | **这是最大价值**(TSF 的 founding 栏) | 你只有 Free/Paid 两档,用不上这个 |
| 归档可按栏浏览 | 篇数多了才有意义 | **0 篇的时候,4 个空栏比没有栏更难看** |
| 显示产品结构 | 一眼看懂你卖什么 | 过度分栏 = 每栏 2 篇 = 像烂尾工程 |

> **关键判据:JB 有 1,259 篇也不需要分栏;TSF 有 355 篇才用 4 个栏。**
> **你有 0 篇。**

## 三、三个方案

### 方案 A —— JB 式:零分栏

```
全部进主 feed,用标题约定区分
导航栏钉 6 篇常青证明页
```

**优点:** 不拆列表、每篇触达全员、0 篇时最不尴尬、当天就能做
**缺点:** archive 长大后不好逛
**适合:** 前 3–6 个月

---

### 方案 B —— TSF 式:开满 4 栏

```
主 feed:How Much(旗舰)
├─ Method(仓位方法库)
├─ The Ledger(月度业绩)
├─ Signals(个股)
└─ Testimonials
```

**优点:** 产品结构一眼清楚
**缺点:** **开台时每栏 0–1 篇,看起来像弃坑**;拆散列表;你没有 founding 档,用不到栏目付费闸

---

### 方案 C —— 混合(**建议**)

```
主 feed          How Much —— 旗舰,每期「筛选 + 数字」
├─ Method        仓位方法库(免费层,05_SIZING_TERRITORY 的 20 篇)
└─ The Ledger    月度业绩 + 全部亏损

导航栏(不是栏目,零成本,立刻做)
  我的方法 · 完整业绩 · 每一笔亏损 · 我做过的一次失败研究 · 测量栈 · 我怎么定 size
```

**两个栏 + 主 feed。** 理由:

1. **`Method` 必须成栏。** 它是会长到 20+ 篇的知识库,**天然需要被浏览和被链接** —— 这正是 TSF 的 `Trading Knowledge` 栏在做的事。而且它是免费层,拆列表的代价最小(本来就想让所有人看到)
2. **`The Ledger` 成栏。** 月更、格式固定、是你对两家的最大不对称优势。**独立成栏 = 让人能一口气翻完你所有的业绩披露** —— 这个动作本身就是转化
3. **旗舰不进栏,留在主 feed。** 主 feed 触达最全,旗舰要吃满
4. **Testimonials 先不开。** 0 订阅者,开了是空的。等有 20 条真实反馈再说
5. **Signals 不单开。** 个股就在旗舰里,单开一栏等于把旗舰拆成两半

---

## 四、导航栏才是现在最该做的事

**Sections 是给已有存量的人用的;导航栏是给 0 篇的人用的。**

JB 排第 3、1,259 篇,**一个分栏没有,但导航栏钉了 6 篇**。他把说服路径放在导航,不放在分栏。

**你的 6 个位置(素材已写好大半):**

| 导航位 | 指向 | 证明什么 |
|---|---|---|
| 我的方法 | 两腿仓位那篇(#2) | 方法透明 |
| 完整业绩 | I Lose More Often Than I Win(#3) | 真实且敢亮亏损 |
| 我怎么定 size | 仓位公式 | **差异化本身** |
| 一次失败的研究 | null result(#5) | 诚实 |
| 测量栈 | dashboard 截图 | 能力 |
| 开始这里 | Start Here(#1) | 导航 |

**成本为零,当天可做,TSF 没有,而你的素材已经写好了五个。**

---

## 五、要和你确认的三点

1. **两个栏够不够?** 我的判断是够,而且宁可少 —— 空栏的伤害大于缺栏。三个月后 `Method` 满了 10 篇,再考虑加
2. **`Method` 全免费还是半免费?** 我倾向**全免费**(见 `03_PRICING.md`:方法免费、应用付费)。这样它同时是知识库和漏斗,拆列表也无所谓
3. **中文刊(`fluxuscapitalcn` 激浪资本)要不要同构?** 建议**先不分栏**,走方案 A —— 两个刊都在 0 篇,中文那边更要轻装
