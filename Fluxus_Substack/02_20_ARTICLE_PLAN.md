## 一、先做一个决定:课程会不会被 Substack 吃掉?

课程是要卖的产品(Squarespace Member Area,卡在 plan 升级 + Stripe)。**如果 Substack 免费发课程原文,课程就没了。**

三个选项:

| | 做法 | 后果 |
|---|---|---|
| **A** | Substack 直发课程原文 | 档案库瞬间填满,**但课程作废** |
| **B ✅ 建议** | Substack 发**"为什么成立"的随笔**,课程是**"怎么练"的系统** | 两个产品不重叠;Substack 变成课程和订阅的共同漏斗 |
| **C** | 课程整包塞进 founding 档 | 简单,但把一个可独立定价的产品降级成赠品 |

**B 的分工线,写死它:**

> **Substack 给你一个想法,让你今天看盘时想起它。**
> **课程给你一套动作,让你练到不用想。**

具体差别:课程有 `右手 · The Core Drill`(每日 45–60 分钟训练)、检查清单、逐步骤序列。**这三样永远不进 Substack。** 随笔可以讲清楚压缩为什么会导致扩张,但不给你那份让你每天练它的训练表。

TSF 验证过这条路可行:他互动最高的三篇里有两篇是教学长文(Ultimate Guide 36 赞、10 Core Concepts 28 赞/11 评)——**教学是他最好的内容,而他连课程都没有。你有。**

## 五、一课 → 一篇的改写配方

课程和信件是两种文体。课程是**教学结构**(Why this matters → The only model you need → Core Drill → 编号要点)。信件是**论证结构**。直接贴过去会读起来像讲义,那是 AI 味闸的头号触发点。

| 课程里的 | 信件里改成 |
|---|---|
| `Why this matters` | **删掉。** 换成一个具体场景或一次自己的亏损。信件不预告价值,直接给 |
| `The only model you need` | 这是文章的**论点**,提到最前面当第一段 |
| `右手 · Core Drill` | **整节删掉。** 这是课程的护城河,不外流 |
| 编号要点 1/2/3 | 保留,但**每条里必须塞一根非教科书的刺**(七道闸的 AI 味闸) |
| 中文对照 | Substack 版先做纯英文;中文另开刊(`00_SETUP.md` §8 方案 C) |
| — | **新增:回指开场。** 「上次我说 X,这周它做了 Y」 |
| — | **新增:失效条件。** 「什么会让我认为这条不成立」——过收藏闸的唯一方式 |
| — | **新增:P.S.** 一句暖的,把这篇翻译成一条可迁移判据 |
| — | **新增:课程指路。** 结尾一行,不吆喝:「这条的训练版在课程 L3。」 |

**长度目标:** 1,200–2,000 字 + 8–15 张图。课程一课约 1,700–3,400 字,所以**一课通常够写 1–2 篇随笔**,别硬塞成一篇。
