# 01_start_here · R1 结构轮(10 版)

*判据(Andy 定的三项 = 结构/修辞/用词,本轮只比**结构**):*

| # | 判据 | 为什么是它 |
|---|---|---|
| ① | **陌生人三秒懂** | 这是导航第一位,点进来的人对 Fluxus 一无所知 |
| ② | **最强的东西在最前** | 现状里最好的一句("Everyone tells you what to buy…")埋在第 7 段 |
| ③ | **不依赖未定的产品口径** | `09_PRODUCT_DEFINITION` 三条未定 —— **依赖它的结构现在发不了** |
| ④ | **不和固定块 A 重复** | 块 A(What this letter is / is not)每篇都有,Start Here 不能把它当自己的开头 |
| ⑤ | **有一段只有他能写** | 可替换的段落 = 任何人都能写 = 没有护城河 |

---

## 现状诊断

```
1. 块 A(What this letter is / is not)      ← 固定块当开头,这篇没有自己的开场
2. "The market is a game…" + 个人经历        ← 无小标题,读者不知道在读什么
3. 市场观(crowd/funds/我的 edge)
4. "So there are no calls here…"
5. ⭐ "Everyone tells you what to buy…"       ← 全文最强的一段,在第 7 段
6. "I won't promise to be right…"
7. What you'll get                          ← 🔴 整节是作废口径
8. The book(占位)
9. P.S.(好,保留)
```

**三个硬伤**:最强段落埋太深 · 固定块顶掉了开场 · 第 7 节现在发不了。

## 十版

**V1 · 现状**（基线）

---

**V2 · 缺口开门** —— 把第 5 段提到最前,全文从"缺口"长出来
```
① 缺口:Everyone tells you what to buy. Almost nobody tells you how much.
② 缺口的代价:名字对了仓位错 / 对了两次第三次还回去（"我这三种人都当过"）
③ 我怎么补:R 是固定的,先于点击设定
④ 凭什么信我:331 笔 / 39.9% / 3.40x / 亏损全给你看
⑤ 谁在写(压到 120 字以内)
⑥ 块 A
⑦ P.S.
```

---

**V3 · 数字开门** —— 第一屏全是可核对的数
```
① 331 笔。39.9% 赢。年份还是成立的。
② 为什么成立:3.40x —— 然后立刻说这不是运气,是仓位
③ 缺口段
④ 方法(R=0.25%,止损定仓位)
⑤ 谁在写
⑥ 块 A · P.S.
```

---

**V4 · 认错开门** —— 从"我当过那三种人"进
```
① 我右过名字、错过仓位;我对过两次、第三次全还回去。这三种人我都当过。
② 那三种人缺的是同一样东西:一个"多大"的数
③ 缺口段
④ 我现在怎么做 + 记录
⑤ 谁在写 · 块 A · P.S.
```

---

**V5 · 一笔交易开门** —— 拿已发布的 MRNA 当钩子
```
① 上周我写了一笔 +23R 的交易。这封信要讲的不是那笔交易,是那 0.25%。
② 从 0.25% 讲开:R 是什么、为什么先于点击
③ 缺口段 · ④ 记录 · ⑤ 谁在写 · 块 A · P.S.
```

---

**V6 · 反推荐** —— 先说这不适合谁
```
① 如果你想要有人告诉你现在买什么,这封信会让你失望。
② 如果你已经知道买什么、但每次都不知道下多大 —— 那这封是给你的
③ 缺口段 · ④ 方法 · ⑤ 记录 · ⑥ 谁在写 · 块 A · P.S.
```

---

**V7 · 六个问题** —— 用"读完你能回答什么"当骨架
```
读完这封信你会知道六件事:
① 我怎么决定买哪一个   ② 我怎么决定多大
③ 我什么时候认错       ④ 我的记录长什么样
⑤ 我不做什么           ⑥ 我凭什么
（每条一段,每段落在一个数字上）
```

---

**V8 · 词条体** —— 把 "how much" 当一个词条来定义
```
how much (n.) — 决定你这一年的那个数,几乎没人写它。
① 定义 ② 为什么没人写 ③ 我怎么算 ④ 记录 ⑤ 谁在写 · 块 A · P.S.
```

---

**V9 · 时间线** —— 七年压成一段递进
```
① 日内交易,被教做人 → ② 学防守 → ③ 转波段 → ④ 今年 331 笔
每一格落一个数;终点是"所以这封信只讲一件事:多大"
```

---

**V10 · 混合(V2 骨架 + V4 的认错段 + V3 的数字前置)**
```
① 缺口(V2 ①)
② 认错:那三种人我都当过(V4 ①)—— 作为缺口的证据,不是自谦
③ 数字:331 / 39.9% / 3.40x(V3)—— 紧跟认错,构成"我知道我在说什么"
④ 我怎么补这个缺口:R 固定、先于点击、止损定仓位
⑤ 谁在写(≤120 字)
⑥ 块 A(固定块,放末尾而不是开头)
⑦ P.S.（保留现状那段,它是全文最好的）
```

## 淘汰

- **V1 现状 9 分**:三项硬伤全中。尤其 ③ —— "What you'll get" 那节引用的三个口径(`Size & Stop` / 2–3x 周 / Weather Report 周一)**全部已作废**,原样发出去就是承诺了不存在的产品。
- **V6 反推荐**:三秒懂满分,但开头就说"会让你失望",**把 40% 的人劝走了才开始讲**。这个装置适合付费页,不适合 Start Here。
- **V7 六个问题 / V9 时间线**:都成立,但**都是清单**——清单没有"最强的一句",第 ② 项永远拿不到高分。
- **V8 词条体**:很有性格,但"三秒懂"只有 3 分,而且它和 `content_idea_p_zhirenti`(指认体)撞文体,那个更适合 X。

## ⚠️ 结构轮解决不了的一件事

**V10 的骨架里没有"What you'll get"节** —— 那节依赖 `09_PRODUCT_DEFINITION.md` 的三条未定项
(频率 / 持仓表 / size-and-stop 口径)。

**处理方式**:R2–R5 按 V10 骨架推进,**"你能拿到什么"留一个空槽**,等 Andy 定案后填。
好处是这篇的其余部分**现在就能发** —— 它讲的是方法、缺口、记录,三样都不依赖两档分界线。
