*2026-08-26 定。配 `tools/daily_recap.py --post` 使用 —— 机器把盘面和分母填好,你写四行。*
*目标:**十分钟以内**。写不完就砍掉「为什么是它」,别砍分母。*

## 用法

```bash
python3 Fluxus_Substack/tools/daily_recap.py --post            # 最新一天
python3 Fluxus_Substack/tools/daily_recap.py --post --date 2026-08-19
```

配图文件名规范(**这一条比模板本身重要**):

```

```

## 模板本体

```
〔图〕

$TICKER · <setup名> · in <价> / stop <价> / <x.xx> ATR / <n>%

为什么是它：<一到两句。今天这个主题/这只票凭什么排在别的前面>
我看到什么：<一到两句。入场那一刻屏幕上的东西,不是事后的道理>

盘面：<机器填>
所以：<一句。上面那些读数让我把哪个数调了 —— 或者「一个数都没动」+ 为什么>

明天等：<一个条件,不是一个名字>

<机器填:今年 N 笔 · 胜率 · 累计 R>
```

---

## 四条规矩(比模板重要)

### 1. 「所以」那一行不能省

`盘面` 是读数,任何人都能生成。**`所以` 是从读数走到仓位的那一步 —— 那条路径没有别人走完过**
(`05_SIZING_TERRITORY` 第 14–17 条:TSF 有 regime 模型也有仓位指南,但他从不把两者连起来)。

**一个数都没动也要写,并说明为什么。** 「什么都没变」是判断,不是空白。

### 2. 「明天等」写条件,不写名字

| ✅ 条件 | ❌ 名字 |
|---|---|
| 20日上方回 55% 我才加风险 | 我明天要买 XYZ |
| 贵金属那组 persistence 到 5 天我才认 | XYZ 到 50 我进 |

三个理由:
- **条件是教学,名字加价格是信号** —— 信号是 $99 那档的东西,这条线靠这一行的写法守住
- 条件失败读作「我早了」,名字加价格失败读作「我错了」
- **条件可以被明天的自己回访**,名字只能被验证对错

### 3. 分母永远在场

你要挑赢的发 —— 可以,JB 就是这么干的而且做到了 15,000 订阅。
**但挑赢的只有在分母被藏起来时才是欺骗。**

图会被人截走、转走、脱离上下文。所以 `今年 363 笔 · 39.9% · +330R` **要烧进图里**,
不是只写在推文里。挂着它,你想挑哪笔挑哪笔。

### 4. 文字不烧进图,只有三样烧进去

| 烧进图 | 留在图外 |
|---|---|
| ticker · 日期 · 价位 · setup 名 · entry/stop 标记 · **分母** | 理由、故事、callback |
| *和图分开就废了* | ***它是产品*** —— 要可搜索、可编辑、可按平台改写 |

## 动物性放哪

Andy 08-26:「我还想要展现的是我的 aggressive animalistic ambition,恐惧和 trading 让我一直成长。」

**它不进「盘面」和「所以」那两行**(那两行是冷的,冷是它们的功能)。
它进 **「我看到什么」** 和 **亏损那天的那一句**。

> **没有动物性,仓位管理就是记账。有了动物性,它是笼子。**

⚠️ **唯一的规矩:动物永远和代价绑在一起。**
`我买了刚卖掉的两倍` ✅ 成立 —— 因为止损写在旁边。
`我天生是猎手` ❌ 是噪音,而且是 fintwit 上最烂大街的人设。

**你的动物性可信,恰恰因为你敢公开 39.9% 和 17 连亏。别人演动物性,因为他们没有分母。**

⚠️ **不要每天写情绪。** 编出来的情绪读得出来,而且比没有情绪更糟。
真实的时候写,大多数日子跳过。

## 没交易的日子

**不跳过。** 那种日子占你全年的大多数,而读者最缺的正是这个。

```
〔图:今天的盘面/轮动截图〕

今天没动手。

为什么没有：<在等什么条件>
盘面：<机器填>
所以：<一句>
明天等：<条件>

<分母>
```
