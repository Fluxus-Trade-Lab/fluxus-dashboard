## 〇、v1 错在哪

**我又做了一次「供给侧设计」。**

v1 的做法是:先看你手上有什么,再把它们塞进六个格子。缺社会证明,就找一个手头有的东西顶上去。
**这和我上次把 Weather Report 当旗舰是同一个错误 —— 理由都是「你已经有这个了」,而不是「这个是对的」。** 第二次了。

**你的原则是对的:该空着的格子就空着,然后去挣。**
用手头的东西填格子,等于让现有的库存决定产品长什么样。**正确的顺序是先定义该有什么,再去看缺什么。**

### 关于行为审计,你的理由比我的好

我把它放进导航的理由是「没人这么做」。**新颖 ≠ 正确。这是个坏理由。**

你的理由更硬,而且有三层:
1. **行为审计是私人改进工具,不是营销资产**
2. **它是时间性的,而导航栏是永久位置。** 你希望半年后这条诊断变成假的 —— 那就不该把它钉在一个永久位置上
3. **你正在请人相信你的纪律,同时在头条挂一条「我有纪律问题」** —— 方向是反的

**但有一条区分要留住**(否则会连带砍掉不该砍的):

```
亮亏损     结构性、永远为真      → 留  (39.9% 胜率 · R 分布 · 130 次纯止损)
自我诊断   时间性、你要它变假    → 拿掉(反复攻破掉的论点)
```

**「我输的次数比赢的多」十年后还是真的。「我有个坏习惯」你三个月后就该让它变成假的。** 前者是产品,后者是私事。

## 一、正确方法:先定义完整清单,不看自己有什么

**一份付费市场信,应该向一个陌生的怀疑者证明八件事:**

| # | 该证明什么 | 为什么它必须存在 |
|---|---|---|
| 1 | **这是什么 / 你是谁** | 落地即定位 |
| 2 | **结果** | 你到底赚不赚钱 |
| 3 | **不是运气** | 统计有效性,可重复 |
| 4 | **方法透明** | 你实际在做什么 |
| 5 | **产品样本** | 我每周实际收到什么东西 |
| 6 | **社会证明** | 别人拿到价值了吗 |
| 7 | **实盘能力** | 公开时间戳的判断,后来兑现了 |
| 8 | **认错机制** | 你错的时候会不会说 |

**这八条是先验的,和你手上有什么无关。** 下面再对照库存。

## 三、开台导航 = 四格,不是六格

```
Start Here  ·  The Record  ·  I Lose More Often Than I Win  ·  How Much
```

发完第一期后加第五格(产品样本)。

**四格比六格好,而且不是将就:**
- JB 有六格是因为他四年攒了 1,259 篇。**你有四格是因为你诚实。**
- **一个只有四格但每格都硬的导航,比六格里两格是凑的更有说服力** —— 凑的那两格会被人看出来,然后连累另外四格

## 四、空着的两格 —— 怎么挣,什么时候

### 第 6 格:社会证明

| | |
|---|---|
| **需要什么** | 真实读者的具体反馈,**不是"很棒"这种** |
| **怎么挣** | 第 30 / 60 / 90 天各发一次定向提问:**「这封信改变了你的哪一个具体动作?」** —— 问动作,不问感受 |
| **成型标准** | 攒到 **8–10 条能点名具体改变的反馈** |
| **预计** | 3–6 个月 |
| **格名候选** | `What Readers Changed` · `How Members Use This` |

> ⚠️ **不要用「客户好评墙」的形式。** TSF 有一个 Testimonials 栏,读起来像广告。
> **你的版本应该是「他们因为这封信改了什么动作」** —— 具体动作比赞美更有说服力,而且符合你反多巴胺的调性。

### 第 7 格:实盘能力

| | |
|---|---|
| **需要什么** | **公开、带时间戳的判断,后来被验证** |
| **怎么挣** | **旗舰自己会长出来。** 每期都有仓位数字和失效条件 → 发满 10–12 期后,写一篇「前十期说了什么,后来怎么样」 |
| **成型标准** | ≥10 期存量,好坏都列 |
| **预计** | 约 3 个月(每周 2–3 篇) |
| **格名候选** | `What the Last Ten Calls Did` · `The Scoreboard` |

> **这一格是挣来的,不是宣称的 —— 这正是它值钱的原因。**
> 而且它把之前那个「对账」概念放回了正确位置:**不是一个栏目,是一篇由存量自动长出来的导航页。**
