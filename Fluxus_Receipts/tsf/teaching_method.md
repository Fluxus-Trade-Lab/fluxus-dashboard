## 二、他的教学法:七个可复用的手法

### 1. 从「昨天的战果」切入,不从定义切入

《10 Core Concepts》开篇不是「什么是交易框架」,而是先讲他们最近的一个 setup 昨天涨了 100%,然后才说「今天这篇不一样」。

> **先证明这套东西有用,再讲这套东西是什么。** 顺序反过来读者就走了。

### 2. 标题写成完整句子,而且是「你」的口吻

他的小标题不是名词短语,是对读者说的话:
- 「你必须先定义自己的交易风格」
- 「你会一直犯错」
- 「过程 > 结果」
- 「掌握少数几种打法」

**没有一个是「交易风格的定义」这种词典式标题。** 每个小标题本身就是一条可以单独抄走的建议。

### 3. 编号 + 每条配真实个股

《Ultimate Guide For Pullbacks》的结构:
```
概念 1(EMA21 是区域不是线) → SNDK · BE 两个真实例子
概念 2(均线不总是有效)     → TMDX 反例
概念 3(震仓)               → 实例
概念 4(用 EMA21 移动止损)  → CRDO · HOOD
最佳买点的三种情形          → LEU · IREN …
```
**每一条抽象规则后面立刻跟 1–3 只真实股票的图。** 20 张图 / 4,623 字。

> **关键细节:他专门放反例(TMDX 那条「均线不总是有效」)。** 只给成功案例的教学会被读者的实盘打脸;先自曝失效场景,反而建立信任。

### 4. 「像机构一样思考」的视角切换

反复出现的句式:「SNDK 从机构的眼睛看」「当我交易时 —— 我像机构一样思考」。
**把技术形态翻译成「谁在买、为什么被迫买」**,而不是停在形态识别。这就是他 §三 会讲的 liquidity zone 概念。

### 5. 同一主题隔一年重写一次

- `Guide For Buying Breakouts` — 2025-04(2,613 字,4 赞)→ 2025-06 **重写**(2,761 字,**17 赞**)
- `Earnings Gaps` — Part I(2025-07)→ Part II(2026-01)
- `Sentiment Cycle` / `Panic Cycle` 等周期命名反复回归

> **教学资产是复利的:重写一次,互动 4 倍。** 不是写完就归档。

### 6. 强制收尾:「别对自己太苛刻」

《10 Core Concepts》最后一节和《Risk Management》最后一节都是同一句话的变体 —— **对读者的安慰**。

> 这和你 Voice Bible §4 的「cold to the market, warm to the reader」「P.S. 必须是暖的」完全同构。**他也在做温差,只是放在结尾而不是 P.S.**
> 你的记忆里那条「苛责自己那可不是捷径」「愚蠢的问题都是好问题」—— **同一个东西,你的版本更有味道。**

### 7. 先讲怎么不亏,再讲怎么赚

《Risk Management & Position Sizing Guide》的推进顺序:
```
永远用止损 → 把自己和钱分离 → 算每笔的组合风险 → 怎么算风险
→ 最常见的错误 → 什么是合理的止损位(两种)→ 金字塔加仓
→ 怎么判断股票是否 extended(短期/中期)
→ 「我一个字都还没说仓位该多大」   ← 全文倒数第二节才提到仓位
```

> **这一条对你最重要,而且是个坏消息也是个好消息。**
>
> **坏消息:** 他确实有一篇仓位管理教学稿,不是完全不碰这个题。
> **好消息:** **他把仓位放在最后,而且只在教学稿里讲一次 —— 他的日常旗舰(Focus Stocks)里从来不给数字。**
>
> 也就是说:**他教「怎么算仓位」,但不替你算。你的定位是每一期都替读者把这个数字算出来。** 那个空位仍然成立,而且更精确了:
> ```
> 他:  教你方法,一年讲一次     (教育)
> 你:  每一期都给出数字         (产品)
> ```

## 三、你的 Masterclass 和他的 22 篇对照

| | TSF 教学档案 | 你的 Swing Masterclass |
|---|---|---|
| 体量 | 22 篇 / ~6 万字 | 16 课 / ~3.5 万字 + 附录 |
| 结构 | **零散,按需写,靠标题串联** | **有序,模块化,有前置依赖** |
| 训练 | **无** —— 只有阅读 | **有 `右手 · Core Drill`,每日 45–60 分钟** |
| 语言 | 英文 | **中英双语** |
| 载体 | 付费墙后的文章 | 独立课程产品 |
| 反例教学 | ✅ 有(TMDX) | 待确认 |
| 结尾安慰 | ✅ 有 | ✅ 有(同一种温度) |

**结论:你的课程在结构和训练上比他强,他在「按需 + 复利重写」上比你灵活。**

**两条可以直接搬:**
1. **同一主题隔一年重写。** 你的 16 课不该是写完就冻结的。第二年重写一次,互动会翻倍
2. **每条规则配反例。** 他专门放 TMDX 说明均线会失效 —— 这个手法你的课程可以加强
