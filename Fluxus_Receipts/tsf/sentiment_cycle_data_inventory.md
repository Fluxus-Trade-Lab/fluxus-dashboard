## 三、三条结论

### 1. 他这套里,你已经有的比你以为的多

```
dealer gamma  →  你自建 GEX 引擎(他租 MenthorQ)   ✅ 你更强
广度          →  breadth v2 + 信号引擎              ✅ 你更强
regime 模型   →  已有                               ✅ 平手
主题轮动      →  screener + ticker events           ✅ 平手
```

**他花钱租的最贵那一项(gamma),你是自己造的。**

### 2. 你缺的那些,几乎全是免费的

**AAII · NAAIM · MOVE · HYG · XLP · 油 · IPO 行为 —— 七项全部免费或近乎免费。**
这七项就是他「情绪 + 跨资产」两层的全部内容。**接进 pipeline 是几天的工作量,不是几个月。**

> **优先接这四个**(性价比最高):
> 1. **AAII + NAAIM** —— 每周免费 CSV,直接补上「情绪」整层
> 2. **HYG / 垃圾债** —— 信用领先股票,免费,他自己都说「junk bonds sometimes lead equities」
> 3. **XLP 相对强度** —— 防御资金的去向,一行比值
> 4. **MOVE** —— 债市波动,他专门写了一节说市场讨厌它上行

### 3. 唯一真正买不到的两项,是估算不是事实

**CTA 敞口和 vol-control 敞口都是投行模型的推测值**,SentimenTrader 转售。它们看起来很专业,**但本质是别人的猜测,而且经常修正。**

> **不用追。** 用你的 null-result 纪律看,这两项恰恰是最该标注不确定性的数据,而 TSF 是直接当事实用的。

## 四、他最贵的一节,恰好是你最该自己做的一节

> **「When The S&P 500 Is Up 9% Like Now YTD」** —— 历史类比/基准率。

这是 SentimenTrader 的看家本领,也是全文最有说服力的一节(「历史上出现过 N 次,后来平均如何」)。

**而你手上有比订阅更好的东西:**

```
sequence mining 装置    →  已经能做基准率统计
ticker events 归档      →  历史信号 → 后续表现的对照
null result 的纪律      →  知道怎么不骗自己(pool-matched baseline、多 seed、去重)
```

**你可以生成原创基准率,而不是转述别人的。** 而且因为你踩过那三个坑(baseline 抽错池、单 seed、重复日期灌水),**你的基准率会比 SentimenTrader 的更诚实** —— 至少你会写清楚 n 有多少、样本是不是独立、跨了几个 regime。

> **这是这份清单里最重要的一条:**
> 他这篇文章里最像「独家数据」的那一节,是全篇你最有能力超过他的一节。
> 而且它连接了你已经建好的两套东西(sequence mining + ticker events),它们现在还没有被用进任何对外产品。
