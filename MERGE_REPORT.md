## `scripts/refresh_case_study_ohlc.py` — resolved, no capability lost

Both branches implemented per-trade case-study cards (gex `1c866c4`, main `577508a`). On inspection
the two implementations are **not** divergent designs: the shared body of the file is byte-identical.
The entire 28-line delta is additive on the gex side:

- `_local_last_date(sym)` — a check-before-fetch helper reading the last stored `ohlc_2y` bar, so a
  file the daily ticker pipeline already refreshed is not refetched.
- `main(tickers, force=False, fresh_within=None)` — skips symbols already fresh, printing
  `"{SYM}: already fresh (through {date}) — skipped"`.
- `__main__` — a `--force` flag, and a freshness cutoff of `market_today() - 4 days` (ET via
  `pipeline.marketcal`, weekend-tolerant).

Main contributed nothing in this file that gex lacks, so gex's version is a functional superset and
was taken whole. Two cosmetic cleanups applied: the `pipeline.marketcal` import moved below
`pathlib` to keep import grouping tidy, and an unused `date` import dropped from the `__main__`
block (only `timedelta` is used). No behavioural change.
