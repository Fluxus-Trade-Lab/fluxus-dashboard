# Daily Market Recap — 标准件

*已在跑的成品,不是设计稿。发给 Discord 会员(**$100 层的核心交付**)。*

> **产品定义:信息效率。客观、技术、无感情、无营销。目标是最快的汇总与传递。**
> ⚠️ **与 `How Much`(Substack 周信)是两个产品,两种寄存器,不合并。** 对照见文末。

---

## 骨架(九块)

```
📊 <日期> Recap: <一句话说清今天>     ← 标题是判断,不是日期
🎯 The Big Picture                    ← 叙事段(唯一的散文块)
📈 Index Action                       ← 等宽表 + Trend 一行
🟢 Leaders & Standouts                ← 等宽表
⚠️ Still Repairing (Monthly Losers)   ← 反面清单
📊 Volume & Structure                 ← 含 Read: 一行
📝 Actions                            ← 含 Mode: 一行
📅 The Rules                          ← 编号条件 ⭐ 收藏价值在这
🎓 <本周主题的真标题>                  ← 教学段。**唯一有观点的部分**
```

## 每块的规格

**📈 Index Action** — 三栏等宽,三秒扫完:`涨跌% | 技术状态 | 语境`
覆盖 SPY / QQQ / RSP / DOW / IWM / VIX。**RSP 是最好的整体代理**,别漏。
表下一行 **`Trend:`** —— 短期状态 | 龙头灯号 | 长期位置。**表是原料,这一行是货。**

**🟢 Leaders & Standouts** — `ticker | 动作 | 为什么 | 备注`

**⚠️ Still Repairing** — 月度输家 + 共性一句(如「多数 AI 名字在下行 50 日线 gap-and-fail」)。**很少人写反面清单,这是差异化。**

**📊 Volume & Structure** — 时间线 + **`Read:` 一行**(全篇第二个「货」)。
> 亚洲/隔夜按需嵌在这里(例:`Wednesday: Violent liquidation (Korean memory + SA fund)`),**不设固定栏目** —— 有意义才出现。

**📝 Actions** — `Sold / Trimmed / Added` + **`Mode:` 一行**。
Mode 一句话交代当前状态,**零仓也写得出来**(如 `Essentially all-index now, waiting for FTD`)。
*可加一列 `x% port risk` → 台账完整化(与 Substack 的「how much」定位同源)。*

**📅 The Rules** — 编号 5–8 条,每条是**可证伪的条件**。
**这是全篇收藏价值所在**,也天然生成次日/次周的翻帖素材。

**🎓 教学段** — **每期给一个具体标题,不用固定栏目名**(例:*"Change of Character" Off a Capitulation Low*)。
命名的主题才会被记住、被等待、被连载(Le Shrub 的 *Wall of Supply* 六部曲同理)。
**这是整份 recap 里唯一主观、有声音的一块 —— 它是周信的 DNA。**

## 与周信的关系

| | **Daily Recap** | **How Much(周信)** |
|---|---|---|
| 卖什么 | 信息效率(省时间) | 视角(一种看法) |
| 语气 | 客观、技术、无感情 | 主观、人话、有人设 |
| 读者 | Discord 会员(在场) | Substack(有正职) |
| 价值单位 | **一天发生了什么** | **一个想法** |
| 频率 | 每日 | 每周 |
| 层级 | Discord $100 | Substack $40 |

**桥 = 🎓 那一段。** 周信不是「本周 recap 的合集」,而是**这一周五段 🎓 里,挑一个长出来的那个**。零新增习惯 —— 信的胚胎每天都在写,只是被埋在数据下面。

### 市场定价佐证(2026-07-31 调研)
日更 recap 型产品在 Substack 上卖 **$90–99/月**(TMT Breakout 每日两封 $90;Capital Flows 每日报告+直播 $99),**高于声音型周信**(Le Shrub $44、Doomberg $40)。
→ recap 放在 $100 的 Discord 层,**定价正确**。
→ 但增长画像相反:**日更 recap = 高价低增速**(TMT 438/月,榜里最慢之一);**声音型周信 = 低价高增速**(Le Shrub 986/月)。两层各司其职,**合并会两头不讨好**。

Don't chase breakouts in a tape that keeps rejecting them; buy change-of-character names on pullbacks to support with tight stops. **Trigger over indicator** - capitulation candles hint at a low, but let price confirm the reclaim before committing fresh capital.
