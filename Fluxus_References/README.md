# Fluxus References — Reading & Inspiration

Reference kit for the **Fluxus** voice (see `../Fluxus_Brand/voice/Fluxus_Voice_Bible.md`). Each item feeds a specific muscle. Drop PDFs / notes in this folder.

## ✅ In the folder

**Trading canon & pseudonymous literary voice**
- [x] **Edwin Lefèvre — *Reminiscences of a Stock Operator*** — trading as literature. The canon.
- [x] **"Adam Smith" (George Goodman) — *The Money Game*** — pseudonymous, witty, literary narrator. Your direct ancestor. *(Goodman-George-JW-1377.pdf)*
- [x] **Fred Schwed Jr. — *Where Are the Customers' Yachts?*** — deadpan Wall Street wit = the register.
- [x] **Michael Lewis — *Liar's Poker* + *The Big Short*** — character, narrative, comedy.

**Method, probability & the monk temperament**
- [x] **Howard Marks — Oaktree Memos (complete)** — patience, second-level thinking, cycles, memo-as-brand.
- [x] **Nassim Taleb — *Fooled by Randomness*** — the ally of volatility in book form. Most on-brand.
- [x] **Annie Duke — *Thinking in Bets*** — "a position, not a prediction."
- [x] **Mark Douglas — *Trading in the Zone*** (+ summary) — probabilistic detachment; the calm player.

**Art ⟷ markets**
- [x] **Don Thompson — *The $12 Million Stuffed Shark*** — how art prices are set by narrative/consensus. The banana-top bridge.
- [x] **John Cage — *Silence*** — chance, indeterminacy, deadpan wit. Root of the Fluxus movement.

**Prose & digital-writing craft**
- [x] **William Zinsser — *On Writing Well*** — plain, tight English. Antidote to typos and slop.
- [x] **Writing for Digital Media** — format craft for newsletter / Substack / X.
- [x] **Writing 21st Century Fiction** — narrative craft, character, voice on the page.
