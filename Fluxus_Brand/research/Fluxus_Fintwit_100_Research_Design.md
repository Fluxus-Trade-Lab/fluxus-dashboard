# Fintwit Top 100 调研设计 —— 变现地图 · 声音解剖 · 蹭号名单

*样本:Kaito smart-following Top 100(用户 2026-07-31 提供)。承接 `Fluxus_Brand/research/Fluxus_X_Competitor_Teardown.md`(10 账号深度拆解,2026-07-28)—— 那份回答「什么内容会爆」,这份回答「**谁靠什么赚钱、用什么情绪、我们该蹭谁**」。*

---

## 一、先说清楚两件事(否则这份调研会骗自己)

**1. 真实转化率是拿不到的。** 没有任何公开渠道能给出「X 粉丝 → 付费订阅」的真实比例。任何声称给出转化率的调研都是编的。
→ 我们改用**可观测代理指标**,并且每个数字都标注来源和精度:

| 想知道的 | 拿不到 | 可观测代理 | 精度 |
|---|---|---|---|
| 付费转化率 | ✗ | **Discord 邀请页公开成员数 ÷ X 粉丝数** = 群转化率 | 硬数字 |
| Substack 付费数 | ✗ | 是否上 Substack Finance 榜(付费榜)+ 页面自报 "N subscribers" | 半硬 |
| X 订阅人数 | ✗ | 锁内容帖的回复/点赞数 vs 免费帖(锁帖互动 ≈ 订阅者活跃下限) | 弱,只做量级 |
| 客单价 | ✓ | Substack 定价页 / Discord 落地页 / X Subscribe 弹窗报价 | 硬数字 |
| 收入 | ✗ | 客单 × 订阅量级 → **明确标注「估算」** | 只给数量级 |

**2. 100 个账号不值得同等深度。** 上一份 10 账号的洞见密度证明:决策来自深挖,不来自铺开。但铺开有它自己不可替代的价值 —— **只有全量扫描才能给出「价格分布」和「模型占比」这种市场结构**,以及一份穷尽的蹭号池。
→ 所以分三层,深度不同、产出不同。

## 二、三层结构

### Layer 1 · 全量普查(100 个,浅)
**目的:市场结构 + 蹭号池初筛。每账号约 3 次浏览器动作。**

采集字段:
- `handle_verified` —— 校正后的真实 handle(名单已发现失效项,如 `@Remztrades` → `@Remzztrades`)
- `followers`
- `bio_positioning` —— 他给自己贴的标签
- `external_link` —— bio 外链 + 落地页类型(Substack / 自建站 / Discord / linktree / 无)
- `has_x_subscription` —— 主页是否有 `Subscribe to @X` 按钮 + 是否有 superfollows tab(硬信号)
- `funnel_destination` —— Substack / X 订阅 / Discord / 课程 / 基金 / 无(纯个人品牌)
- `pinned_type` —— 战绩 / 格言 / 教学长文 / 自我介绍 / 产品广告(上一份已证明置顶类型决定长期复利)
- `daily_views_band` —— 近期帖曝光中位数量级

### Layer 2 · 变现解剖(约 25 个,中)
**筛选条件:有真实付费漏斗 且 粉丝量级 10K–300K(和我们同一场比赛)。名人/机构/基金经理不进这层 —— 他们的漏斗是不可复制的。**

追加字段:
- `price` —— 月费 / 年费 / 有无终身价 / 有无免费档
- `tier_structure` —— 单档 / 多档 / 免费群+付费群
- `paywall_style` —— 全锁 / 部分锁 / 全免费(信里才有仓位)
- `discord_members` + `群转化率 = members ÷ followers`
- `funnel_mechanics` —— 从 X 到付费的**具体动作链**(bio 链接?置顶?每帖 CTA?锁内容预告?免费群养熟?)
- `cta_frequency` —— 每 10 条帖里有几条在卖(上一份已证明:锁内容预告会砍 7–16 倍触达)
- `proof_asset` —— 他用什么建立信用(战绩截图 / 券商对账单 / 教学长文 / 名气 / 无)

### Layer 3 · 声音解剖(约 12 个,深)
**只给声音上可偷、或定位上正面冲突的账号。每个读 15–20 条近期帖 + 置顶 + 最高互动帖。**

## 三、声音编码表(这份调研的核心,回答「制造焦虑还是数据流」)

对每个 Layer 3 账号打四组码。**不写形容词,只打码 + 引一条原帖当证据。**

**A. 情绪引擎(他靠哪种情绪让你留下?可多选,标主次)**

| 码 | 名称 | 长这样 |
|---|---|---|
| E1 | **恐惧 / 焦虑** | 崩盘预警、"你还没意识到"、系统性风险叙事 |
| E2 | **贪婪 / FOMO** | 翻倍、抓住、名额有限、别人已经上车 |
| E3 | **优越 / 嘲讽** | 我早说了、踩踏对手、蠢钱 |
| E4 | **归属 / 共情** | 我们都一样、活下来、你不是一个人 |
| E5 | **求知 / 掌握感** | 体系、拆解、"你也能学会" |
| E6 | **娱乐 / 身份** | 段子、梗、角色扮演、圈内黑话 |
| E7 | **权威 / 内幕** | 机构视角、流数据、"你看不到的东西" |

**B. 证据形态(他拿什么当地基?)**
`P1 数据流` · `P2 图表` · `P3 叙事/寓言` · `P4 纯断言` · `P5 收据(带时间戳的旧判断)`

**C. 语言指纹(可偷的技术)**
句长中位数 · 有无口头禅/专属词汇 · 有无固定角色 · 有无自嘲 · 感叹号密度 · 第一人称密度 · 中英/俚语层级

**D. 付费钩子**
`H1 免费长文养熟` · `H2 锁内容预告` · `H3 战绩` · `H4 稀缺/名额` · `H5 纯声音(不解释,自己来找)`

> **判读逻辑(我们要的答案在这里):**
> 把「情绪引擎」× 「变现终点」交叉制表,就能看出 **靠 E1/E2(焦虑+FOMO)的人最终卖什么、值多少钱、留存如何**,对比 **靠 E4/E5/E6(共情+教学+幽默)的人**。
> 上一份的先验假设是:**E1/E2 换来曝光和吵架,E4/E6 换来喜爱,E5 换来购买意向**(Remz 赞/曝光 0.24% vs Za 1.9%,8 倍差)。这份调研在 100 个样本上验证或推翻它 —— 如果推翻,我们的品牌路线要改。

## 四、蹭号打分(Layer 1 全量都打,产出排序名单)

蹭号的听众**不是大号本人,是他底下的几千个散户**(见 Playbook §2)。所以评分不看他多红,看**他的评论区是不是我们的教室**。

```
蹭号分 = 0.30·R + 0.25·M + 0.25·G + 0.10·H + 0.10·B   (各项 1–5)
```

| 项 | 含义 | 5 分长什么样 |
|---|---|---|
| **R 触达** | 评论区实际人流 = 近期帖曝光中位数 | 稳定 50K+ |
| **M 受众匹配** | 他的读者会不会成为我们的订阅者 | 英文散户 · 自己下单 · 关心风险和仓位 |
| **G 空位** | 评论区缺不缺「给测量的人」 | 满屏情绪/表情包/"多少目标价",**没人给数字** |
| **H 主人回复率** | 他回不回评论(回你 = 二次曝光) | 经常回小号 |
| **B 品牌相容** | 出现在他底下伤不伤反多巴胺人设 | 冷静派、无 pump、无喊单 |

**反直觉但重要:G 高的往往是我们看不上的账号。** 一个满屏 FOMO、评论区全是「still good entry?」的大号,恰恰是「冷静报个数」最扎眼的地方。**看不上他 ≠ 不该住在他评论区。**
反过来,zastocks 这种评论区已经很成熟的账号,G 低 —— 我们在那里不显眼。

## 五、扫描波次(按预期价值排序,不按名单顺序)

| 波次 | 数量 | 是谁 | 拿什么 |
|---|---|---|---|
| **W1** | ~25 | 和我们同场比赛的操盘手/教学号(10K–300K,有付费漏斗) | Layer 1+2 |
| **W2** | ~35 | 中量级操作者、声音型账号 | Layer 1,挑出 Layer 3 候选 |
| **W3** | ~40 | 名人 / 机构 / 基金经理 / 匿名梗号(漏斗不可复制) | **只做 Layer 1 + 蹭号分** —— 他们对我们的唯一价值是**评论区** |

W3 这批(Burry、Gundlach、Chanos、Loeb、Tom Lee、Shkreli、WSB…)**不要浪费深度**。他们不卖订阅,他们卖名气,学不了。但他们的评论区是全平台最贵的地皮。

## 七、方法与诚实边界

- **数据来源:** 登录态 Chrome 抓 X 公开数据(含公开 views);Substack/Discord/落地页公开页面。**不做任何付费订阅**,所以锁在墙后的内容我们只知道价格和形式,不知道质量。
- **快照,非全史。** 和上一份一样:每个账号取置顶 + 近 1–2 周,不是全时间线审计。
- **收入数字一律标注「估算」并给公式。**
- **失效/改名 handle 会被记录**,不做静默替换。
- **不引用锁墙内容,不复制他人原创长文** —— 只做结构与手法的描述,原帖引用限于短句且注明出处。
