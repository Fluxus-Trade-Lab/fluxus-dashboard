## 〇、为什么需要它

整个网页都是数据,**Fluxus 这个人是谁没有画面**。没有画面就没有信任。

但 TE 的做法关键不在"加个吉祥物",在于:

> **系统冷到底,声音暖起来。**

他们一步没让 —— 网格、压缩体、单一橙色、零渐变全都硬着。温度不来自视觉系统,
来自**挂在系统上的一个角色**。冷系统让暖角色显得更有人味,暖角色让冷系统不至于像 Bloomberg。

---

## 一、他是谁

TE 的笑点是**把品牌真正在做的事拟人化**,幽默来自真实:发固件更新的人被更新淹没了。

Fluxus 真正在做的事是:**不停地量,极少地动。**
三千个名字扫完、十二条规则跑完、第 89 次观察记完 —— 结论是一个词:**等**。

所以角色是:**一个在等的人。**

一个普通办公室模样的人,坐在一整面亮着的读数墙前面,**手是停着的**。
周围所有仪器都在跑,他不动。喜剧就在这个比例里。

**关键:他不是大师。** 这个品类里全是大师,反大师才是位置。
他不酷、不神秘、不在游艇上 —— 就像 Mr. Update 不酷,他只是很忙。

### 命名

TE 没把他叫 "Teenage"。他是一个**职务**,不是品牌拟人。

**[v2] 锁定:MR. FLUXUS。** 与 MR. UPDATE 命名结构对仗(MR. + 品牌真正在做的事;
flux = 流、变化 —— 活在变化里的人)。栏目名可直接用 "THE DAILY LIFE OF MR. FLUXUS"。
v1 的两条备选(叙事者拿脸 / THE OPERATOR / MR. WAIT)作废。

## 二、固定道具(每张都出现一两件,不要全上)

| 道具 | 它在说什么 |
|---|---|
| 手写的牌子 | `NOT A CALL` / `WAITING FOR CONFIRMATION` / `NO SIGNAL TODAY` |
| 一个 **NO** 的图章 | 大多数日子的动作就是不批准 |
| 身后一整面读数墙 | 亮着,但他**没在看** |
| 一本小本子 | 一天只写一行 |
| 计数 | `OBSERVATION 089` —— 跟仪表盘上的编号是同一个 |
| **[v2]** "NOT FINANCIAL ADVICE" 的牌子 | 对仗 Mr. Update 的 BUSY 牌;社群戏的核心冲突:都想让他荐股,他烦 |
| **[v2]** 那个贴标签的抽屉 | 真实弱点(对破碎论点的反复进攻);明知不该开,手又伸过去 |
| **[v2]** 猫 | 键盘旁睡觉(常态)/踩键盘下单(偶尔);家里的 Market God 化身 |

## 三、画法规格(跟着 TE 的路子,但不抄他的人)

```
线      手感墨线,黑色,粗细有变化;不要矢量等宽线
阴影    交叉排线(hatching),不用灰色块填充
比例    轻微夸张,表情永远是 deadpan,不笑不怒
文字    画面里的牌子用手写体 —— 这是画面里唯一允许的手写
色      黑白为主。橙色 (#d1600f) 一处,不超过一处
底      直接落在纸色上,不出血、不加框、不加阴影
构图    横幅式的「场景」,不是头像。他要小,读数墙要大
```

## 四、出现在哪(比画成什么样更重要)

| 位置 | 规则 |
|---|---|
| **仪表盘** | 只在**页面最底部**,决定之后。**永远不在顶部,永远不挨着任何测量** |
| **信** | 每期一张,放在开头 |
| **X** | 可独立发,配当天的测量行 |
| **课程** | 章节开场 |

### 三条不许

1. **不许解释数据。** 他不指着任何一个数字,不做箭头,不做说明。
2. **不许庆祝。** 赢了也不举杯 —— 这是反多巴胺那条线的延伸。
3. **不许当 logo 用。** 他是场景不是标记,FLUXUS 那个字标不动。

## 五、他会变(这是不腐坏的关键)

一个静态吉祥物三个月就死了。**场景跟着模式走**,是一小套情境:

| 模式 | 场景 |
|---|---|
| `WAIT` | 读数墙全亮,他在泡茶。牌子:`NOT A CALL` |
| `ADD` | 他终于站起来了,但只挪了一步。牌子:`ONE STEP` |
| `REDUCE` | 他在关灯,一盏一盏 |
| `STOPPED OUT` | 桌上多了一张纸,他在上面盖 `NO`。不沮丧,只是记录 |
| `NULL RESULT` | 他把一整叠研究扔进碎纸机,面无表情 —— 对应零结果那条线 |
