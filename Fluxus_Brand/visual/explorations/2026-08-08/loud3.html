Can the smallest
line on the page
carry the page?

Set two flagged it: the measurement line survived all six pieces but keeps shrinking while the display type grows. A line nobody reads is the same as not measuring, and the whole claim of this brand is that it measures.

So this is a controlled test, not another set of covers. Same day, same data, same subject — only the measurement line changes. If the answer were obvious from taste it would not need running.

The test A: as shipped · B: promoted to subject · C: enlarged in place

A · as shipped — 9px mono
The line is present and genuinely ignorable. At 9px under a 150px number it reads as a caption, and a caption is decoration with a job title. This is the failure set two predicted.
B · promoted to subject
It holds a page on its own — and it is the most Fluxus of the three, because the reading is derived in front of you rather than asserted. But it stops being a cover: there is no image to stop a thumb, and at feed size it will lose. This is a letter interior, not a cover.
C · enlarged in place — 13px, ruled, above the mark
This is the answer. Big enough that the eye lands on it after the number instead of skipping it, small enough that it does not compete. The rule above it does most of the work — it turns a caption into a register entry.

What changes in the spec

Measurement line, revised. Plex Mono 13px (was 9), letter-spacing .08em, 1px rule above it at full width, sitting directly under the frame's bottom margin with the mark on its right. It is no longer the smallest type on the page — the kicker at the top is.

The rule that follows. The measurement line may never be the smallest type in a piece. It is the thing that separates a measurement from a poster, so if it loses the size contest it has lost its job. Cheap to check, and it fails loudly.

And a form B is now legal. Variant B — the derivation as the subject, display type demoted to a label — is worth keeping as its own template for the letter's interior and for X long-form. It is the only one of the three where the reader watches the conclusion being produced instead of being handed it. It is not a cover and should never be used as one.
