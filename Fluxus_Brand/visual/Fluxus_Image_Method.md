## 〇、先说结论:你要建的不是配图库,是一本 Bilderatlas

**Aby Warburg,《记忆女神图集》(Bilderatlas Mnemosyne),1924–1929,未完成。**

黑色板面,上面钉满照片复制品:古代近东、古典、文艺复兴的作品,**和当代的报纸剪报、广告钉在同一块板上**。排列不按年代 —— 同一块板上的图属于同一种情绪。他管这个叫 **Pathosformel(情念形式)**:一个能跨越几个世纪反复重现的情绪姿势。

他真的把**一个打高尔夫的球员**和**《朱迪斯斩首荷罗孚尼》**并置在一起。

> **你的 68 条视觉代码,每一条都是一个 Pathosformel。**
> Messi 手插腰踱步 = 等待的情念形式。Kobe 在空训练馆 = 无人见证的情念形式。
>
> 这不是比喻。这是同一个方法,一百年前就有人做过,而且做成了 20 世纪最有影响力的图像学工程。

**这句话改变三件事:**

1. **项目定义变了。** 不是「给帖子找配图」,是「建一本交易的情念形式图集」。前者是内容运营,后者是可以拿出去讲、可以出版、可以做展览的东西。
2. **高雅 vs 流行的焦虑没了。** Warburg 本人就是混着钉的。Messi 和荷罗孚尼在同一块板上,是这个方法的正统,不是妥协。
3. **交付单位变了。** Warburg 的单位是**板面(Tafel)**,不是单张图。一块板上七八张图并置,观者自己在图与图之间读出那个共同的情绪。**一张图 + 一句话是最弱的形式;一组图不配字是最强的。** 后者才会被截图转发 —— 因为它给了读者一件可做的事:自己发现那条线。

## 三、下一步(仍然不做设计)

**建议的顺序,每一步都是选图,不是排版:**

1. **选 6–8 个 Pathosformel 当第一批板面。** 不是 68 条全上。从你最常说、最有话可说的情绪里挑 —— 大概率是:等待 / 无人见证 / 失败与坠落 / 判断被证明 / 系统自己在跑 / 在错的游戏里。
2. **每个板面配 6–9 张图,横跨三个层级:** 一张艺术史的、一张纪实或新闻的、一张流行文化的。这是 Warburg 的钉法,也是让高尔夫球手和荷罗孚尼共存的机制。
3. **板面不配文字。** 标题最多两个词。让读者自己在图与图之间读出那条线 —— 这是它会被转发的原因。
4. **然后才轮到版式。** 到那时框的问题会自己解决:板面只需要一个黑底和一套编号,Warburg 已经证明了。

*(下一步的具体方向见第五节)*

## 五、诚实评估:你的库存和眼睛,适合这个项目吗

**结论:眼睛对,库存不对,而且两者要分开用。**

**库存不对 —— 三条,都硬:**

1. **`Visual_Content` 十一个分类里只有 17 张图。** 你没有图像库存,你有的是**图像判断力**。所以「从库存里挑」这条路走不通,必须走「按方法生产或收集」。
2. **`Artist_Projects` 里的东西对你的读者基本不可读。** Bas Jan Ader、Barney、Huyghe、Sascha Weidner、John Houck、Aspen Mays —— 这些是慢的、忧郁的、需要前置知识的作品,奖励长时间凝视。X 奖励 600 毫秒的缩略图。中文散户和英文 fintwit 看到 Ader 只会读成「文艺」,不会读成「失败的伦理」。
3. **它们是你的私人品味,不是你的频道。** 这不是缺点,这是位置错了。

**眼睛对 —— 但它的用途是引擎室,不是橱窗:**

Warburg 的钉法、Becher 的类型学、Jafa 的挪用逻辑、Ader 的失败伦理 —— 这些是**方法**。展台上放的应该还是流行文化(Messi、Kobe、游戏、电影),因为它们立刻可读。**方法在下面,素材在上面。** 这正好也是 Warburg 本人的做法:他的学术在底层,板面上钉的是高尔夫球手。

**一句话:别拿你的私人品味当内容,拿它当方法。**

## 六、五个方向(图像产品的方向,不是版式)

| | 方向 | 做什么 | 赢在 | 风险 |
|---|---|---|---|---|
| **A** | **情念形式图集**(Warburg) | 单位是**板面**不是单图。6–9 张图一块板,横跨艺术史 / 纪实 / 流行文化,不配文字 | 智识重量最大,可出版可展览,你的知识直接变成壁垒 | 要读者慢下来;X 上一块板得点开才看得清。**不适合日更**,适合信和年度出版物 |
| **B** | **自摄类型学**(Becher / Gursky,但你自己拍) | 同一机位、同一处理,重复拍同一类东西,几百张成网格。用在市场上:每天同一时刻的同一个画面,连续 250 个交易日 | **零版权 · 摄影师的主场 · 网格天然可截图 · 时间累积本身就是内容**,而且跟 On Kawara / 謝德慶 同构 | 要每天真执行;单张不好看,攒够数量才成立 |
| **C** | **坏图像**(Steyerl) | 故意用低清、被压缩、被转发到失真的图。截图的截图,水印保留 | 理论完整、成本最低、跟你的直觉一致;是反多巴胺的另一种表达:**拒绝精致** | 容易看起来像懒而不是像立场。需要极强的框来说明这是故意的 |
| **D** | **操作性图像**(Farocki) | 只用机器为机器生成的图:成交明细、深度、GEX 曲面、算法轨迹、回测输出。不用任何摄影 | **完全独有 · 零版权 · 无限供应 · 直接来自你已有的 pipeline**。跟「测量 > 观点」最一致 | 冷。情感靠标题和语境,图本身不煽情 |
| **E** | **失败档案**(Bas Jan Ader) | 只做亏损、坠落、错判、爆仓 | **最没有竞争**,最符合「幸存者不是冠军」;Ader 证明了失败可以是作品而不是忏悔 | 需要真实的自我暴露;一有表演感就毁;高频会显得不专业 |

**推荐的组合,不是单选:**

- **B 当主线** —— 日更/周更的骨架。它一次解决版权、签名、日历三个问题,而且**只有你能做**(别人没有摄影师的手和眼)
- **D 当补充** —— 行情给理由的时候出,数据现成
- **A 当重器** —— 每季度或每年一块板,是拿去讲、去投稿、去做展览的东西
- **E 低频高冲击** —— 不做主线
- **C 是一种处理手法**,可以叠加在上面任何一条上,不是独立方向

## 七、情绪类型学的谱系(不是杜塞尔多夫)

*回答:类型学这个思路对,但 Becher 那一支是关于物的、冷的。摄影史上做**情绪**类型学的是谁?*

### 源头:摄影一发明就在做这件事

| 谁 | 什么 | 为什么重要 |
|---|---|---|
| **Duchenne de Boulogne**《人类面相的机制》1862 | 用电极刺激面部肌肉,拍下每一种表情 | 摄影史上**第一次把情绪当成可分类的对象**。冷酷,但这就是情绪类型学的元年 |
| **Darwin**《人与动物的情感表达》1872 | 用 Duchenne 的照片和 Oscar Rejlander 摆拍的照片做插图 | **第一本用照片论证情绪是普遍形式的书。**跟 Warburg 的 Pathosformel 是同一个命题,早了 50 年 |
| **August Sander**《20 世纪的人》 | 按社会角色分类拍德国人 | 类型学,但每张脸都带情感。证明**分类不会杀死情绪**,反而会放大它 |

### 当代的顶点

- **Rineke Dijkstra《Beach Portraits》** —— 同一机位、同一光,拍不同海滩的青少年。**类型学里最强的情绪。**她拍的不是人,是青春期那个还没长好的姿势。另有《Almerisa》:同一个女孩,同一把椅子,拍了 14 年。
- **Hans-Peter Feldmann《100 Years》** —— 0 岁到 100 岁,每个年龄一个人,一张照片。民间的、便宜的、毁灭性的。他是**平民版的 Warburg**。

### ★ 解决你「没空拍、不知道拍啥」的那一位

**Hans Eijkelboom《21 世纪的人》(Photo Notes)**

方法本身告诉你拍什么:

1. 站在人流密集处(他偏爱商场门口),**待 30 分钟到几小时**
2. 先只是看,直到认出**当天的一个共同类型** —— 通常是一件衣服,有时是一个行为
3. 相机挂在脖子上,快门线在口袋里,不举机
4. 回去排成 **9–15 格的网格**,标上日期地点

**为什么这条对你是量身的:**

- **不需要构思。**「今天拍什么」由现场决定,不由你决定 —— 这正是你在日历那一节要的:外部给理由
- **30 分钟。**不是一个需要腾出周末的项目
- **主题天然就是你的品牌靶子:从众。**他拍的是「独特性与同质性的悖论」—— 就是羊群。你每天在骂的那个东西,他找到了拍法
- 网格天然可截图,单张不必好看

### ★ 完全不用拍的那一支(从屏幕上收割)

| 谁 | 做了什么 | 对你 |
|---|---|---|
| **Penelope Umbrico《Suns from Flickr》** | 从 Flickr 抓几千张落日,拼成墙 | **集体情绪姿势的类型学,全部来自屏幕。**零拍摄,零版权焦虑(这正是作品的论点) |

| **Joachim Schmid《Other People's Photographs》** | 把网上捡来的照片按**行为和姿势**分类归档 | 分类逻辑跟你的视觉库一模一样,只是他分的是日常姿势 |
| **Erik Kessels《In Almost Every Picture》** | 找到一整套私人相册重新编辑(如:一个丈夫每年拍妻子同一个姿势) | 现成素材 + 编辑 = 作品 |
| **Taryn Simon《The Picture Collection》**(2013) | 拍纽约公共图书馆按概念分类的图片档案夹(「高速公路」「破损物品」「背影」) | **你视觉库的直系祖先。**一个前互联网时代的、手工的、按概念组织的图像搜索引擎。你在做同一件事,只是主题是交易情绪 |
| **Batia Suter《Parallel Encyclopedia》** | 把书里的图按视觉韵律排在一起,不按内容 | 板面逻辑的书籍版 |

**这一支是给你的答案:类型学不一定要自己举相机。收割也是拍。**

## 八、月度板面 —— 「A Month in a Nutshell」

*你提的:每月一块 Warburg 式板面,无数字无数据,只有情绪起伏和事件缩影。这是对的,把它定死。*

**规格:**

- **一块板 = 一个月。**12 块/年,年底自成一本
- **不按时间排,按情绪弧排。** 这是 Warburg 的核心:同一块板上的图属于同一种情绪,不属于同一个日期。月初的恐慌和月末的恐慌钉在一起,中间隔着别的
- **9–15 张图。** 每块板里必须至少各有一张:艺术史的 · 纪实/新闻的 · 流行文化的。**三层齐全才叫板面,只有流行文化就是拼图**
- **不配文字。** 板面标题最多两个词。日期只出现在角落的编号(如 `TAFEL 08 · 2026`)
- **黑底。** Warburg 用的是黑布,不是设计选择,是为了让图与图之间的空隙变成可读的东西

**为什么它会传播:** 一块板给了读者一件可做的事 —— **自己找出那条线**。一张图配一句话没有这个空间,它把答案说完了。这也是「收藏闸」那一条的图像版:立场只拿赞,**留白才被存**。

**产能:** 每月一次,一次两小时。这是全套里唯一需要你亲自「策展」的动作,其余都可自动化或收割。

## 九、Steyerl:入口是《Liquidity Inc.》,不是那篇文章

你说她有很多把世界/战争/经济游戏化的作品 —— 对,而且有一件是**为你写的**:

**《Liquidity Inc.》2014,30 分钟录像。**

- 主角 **Jacob Wood:2008 年被裁掉的金融分析师,转行去打综合格斗**
- 全片以**水**为主线,用水和极端天气比喻金融资产与数字信息的流动性,以及一种集体性的不稳定感
- 结构套用李小龙那句 **"be shapeless, formless, like water"**
- 手法:实拍 + 电脑动画 + **从网上找来的动态图像**混剪
- 装置是一道弧形坡道,铺蓝色柔道垫和懒人沙发

**三件事同时成立:**一个真实的金融失业者、一个关于 liquidity 的双关、一套完全由挪用素材构成的方法。这是 D 方向(操作性图像)和 C 方向(坏图像)的交汇点,也是「把经济游戏化」的最佳单一入口。

其余相关:《Factory of the Sun》(2015 威尼斯德国馆,电子游戏美学)·《HellYeahWeFuckDie》(2016)·《Duty Free Art》(书,关于自由港与艺术作为资产)。

## 十、我们到底在传什么情绪

*这一节是全篇的核心。前面都是手段。*

### 10.1 第一个判断:交易的情绪不是戏剧的情绪

财经内容传的是**贪婪 / 恐惧 / FOMO / 兴奋** —— 这四个是多巴胺,是赌场的情绪,而且已经饱和了。你的品牌明确反这个。

那还剩什么?剩下的是**交易真实占用时间最多、但几乎从未被画过的那些**:

| 情绪 | 为什么没人发 | 为什么它值钱 |
|---|---|---|
| **等待的无聊** | 不刺激,没人点赞 | 这是交易 95% 的时间。**画出它就等于说了一句所有人都懂但没人敢承认的真话** |
| **正确但没赚到** | 显得无能 | 极度具体,只有真交易过的人才懂。**它是身份认证** |
| **错了但赚到了** | 显得侥幸 | 比上一条更危险也更诚实,几乎无人触碰 |
| **纪律的疲劳** | 破坏「自律」人设 | 不是没纪律,是执行了一年之后的累。**这是你和鸡汤号的分水岭** |
| **被证明之前的孤独** | 需要等结果才敢发 | 你的翻帖机制天然产出它 |
| **平仓后的空虚** | 赢了应该高兴 | 赢了之后那个下午的空。**最反多巴胺的一个** |
| **回撤中的自我怀疑** | 示弱 | 失败档案(方向 E)的主体 |
| **提前下车** | 显得胆小 | 每个人都经历过,没人写 |

### 10.2 第二个判断:情绪由姿势承载,不由题材承载

这是 Warburg 最重要的那条洞见,也是整套方法能不能积累的关键。

> **不要找「表达 X 情绪的图」,要找「承载 X 情绪的姿势」。**
>
> 前者是插图 —— 只能用一次,换个题材就废。
> 后者是 Pathosformel —— 可以跨题材、跨媒介、跨世纪反复出现。**只有它会积累。**

### 10.3 映射表:交易情绪 → 它的姿势

**这张表决定你拍什么、生成什么、收割什么。** 左边是情绪,中间是姿势(不是「什么图」是「什么形式」),右边是已有的库存代码。

| 情绪 | Pathosformel(姿势 / 形式) | 已有 |
|---|---|---|
| 等待的无聊 | **静止的身体,周围的人在动** · 蹲伏 · 坐着看别人打 | V01 V03 V04 V52 |
| 无人见证 | **空场 + 单个身影 + 顶光** · 关掉的灯下还在动的人 | V08 V54 V55 |
| 正确但没赚到 | **看着正在离开的东西** —— 关上的电梯门、驶离的船、刚起飞的飞机。身体朝前,对象在远离 | **缺** |
| 错了但赚到了 | **背对着自己造成的事走开**,不回头看 | **缺** |
| 纪律的疲劳 | **重复动作的第 n 次** —— 打卡、划正字、数数(謝德慶 / Opałka) | **缺** |
| 被证明之前的孤独 | **背对人群** | V34 V38 |
| 回撤 / 自我怀疑 | **下坠的身体**(Bas Jan Ader 的坠落)· 手松开 | V58 V59 |
| 平仓后的空虚 | **散场** —— 空看台、拆台、灯亮起来的剧场、赛后的更衣室 | V12 |
| 提前下车 | **提前离席的空椅子**,座位上还有形状 | **缺** |
| 羊群 | **同一时刻所有人做同一个动作**(Eijkelboom / Vionnet 的方法本身) | **缺** |

**表里那五个「缺」就是接下来要做的事。** 它们不是「找不到图」,是**这个品牌最独有的五个情绪还没有形式**。补上它们,比再加 68 条泛用素材有价值得多。

### 10.4 传递机制:六种,选一种当主武器

| 机制 | 怎么起作用 | 谁在用 | 适合 |
|---|---|---|---|
| **姿势** | 单张图靠形式击中 | Warburg | 日常单发 |
| **并置** | 两张图之间的空隙由读者填 | Warburg 板面 | **转发率最高** |
| **重复** | 情绪靠数量堆出来,单张不成立 | Eijkelboom · Becher · Umbrico | 网格,周更 |
| **序列** | 前后两张构成一个小叙事 | Duane Michals | 翻帖(说过 / 兑现) |
| **缺席** | 不给的那张比给的更强 | Alfredo Jaar | 低频重击 |
| **时长** | 一个姿势被拉长到不适 | Sugimoto · 謝德慶 · Ader | 视频 / 年度 |

**建议:主武器选「重复」(方向 B 的网格),副武器选「并置」(月度板面)。**
前者是产能,后者是重量。「序列」直接嫁接到你已有的翻帖机制上,零额外成本。
