# 海报系统 — 框 + 日历

*在一个只会做柱状图的行业里发美术馆海报。*
*配套:`Fluxus_Visual_Library.md`(图库 68 条)· `../research/Fluxus_Quartr_Teardown.md`(为什么是这两颗螺丝)· `../ops/Fluxus_Content_Ops.md` 第 7 节(这份文件是它的执行细则)*

---

## 〇、一句话

**图是借来的,框是你的。** 68 张图会一直换,版式一次都不能变 —— 第 50 张的时候,读者认出的是框,不是图。

**没有理由就不发。** 每张海报必须有一个外部给的「今天为什么发它」,不能靠心情。

---

## 一、框(定稿:展签 / Wall Label)

选它的三个理由,不是审美:

1. **留白托住图** —— 美术馆墙签的真实结构。图不出血,四周的暖石底就是画框。换任何素材(高饱和海报 / 暗调照片 / 纪实黑白)都被同一片底色统一住。
2. **继承 `DESIGN.md`** —— 暖石 `#fafaf9`、Inter、JetBrains Mono、无渐变无阴影。跟 dashboard 和官网同一套系统,跨平台一致。
3. **底部那行等宽字是「测量位」** —— 这是 Quartr 没有的东西。展签上写的不是材质年份,**是今天的数字**。这一行让它不是语录号。

被毙掉的三个(记录在案,不再复活):

| 版本 | 毙掉理由 |
|---|---|
| 全出血 + 底部黑条 | **平庸闸** —— 所有品牌的第一反应,信息流里最抢眼也最没记忆点 |
| 内描边画框 | 装饰,不承载信息,而且容易显得刻意 |
| 全等宽「收据」版 | 中文在等宽字里塌;这个气质留给翻帖那一条线,不做主框 |

### 规格

```
画幅    1080×1350 (4:5)  X 信息流   |  1600×900 (16:9) 信的封面 / 横版
底色    #fafaf9 暖石     |  深色版 #12110f(暗调照片用)
边距    图四周 2.6em,底部 2.2em
图      不出血,底 #f5f5f4,object-fit: cover
主句    Inter 600,2.15em,字距 -0.01em  —— 英文
副句    Inter 400,1.28em,#78716c      —— 中文
分隔    1px #e7e5e4,压在底部
展签    JetBrains Mono,1em,大写,字距 .1em,#a8a29e
标记    FLUXUS,Inter 700,字距 .3em,右下角,永远在同一个位置
```

### 展签那一行写什么

**默认 = 当天的测量。** 三种合法内容,别的都不许上:

| 场景 | 写法 |
|---|---|
| 日常 | `SPX 7412 · T2108 45 · >20SMA 38%` |
| 翻帖兑现 | `SAID 07.22 · PAID 08.14 · +3.1R` |
| 信的封面 | `LETTER 021 · 2026.08.02` |

**不许写:** 情绪形容词、hashtag、"点击链接"、任何感叹号。

### 出图

```bash
python3 scripts/make_poster.py --code V01 \
    --en "It's a blind spot. That's exactly why cash is the right position." \
    --zh "正因为这是盲区，现金才是最合适的仓位。" \
    --meta "SPX 7412 · T2108 45 · >20SMA 38%"
```

`--code` 从 `visuals/selected/` 取已筛好的图(先跑完筛选台)。也可以 `--image 路径` 直接指定。
`--dark` 深色版 · `--ratio 16x9` 横版 · 输出在 `visuals/out/`,1080×1350 @2x。
框的定义在 `scripts/make_poster.py` 里,改一次全局生效 —— **不要在单张图上手动调**,那就是框失效的开始。

## 二、日历(触发器,不是排期表)

Quartr 的引擎是财报季:外部给定、永不枯竭、每张图自带发布理由。
你的图库是**按情绪索引**的,意味着发图理由来自当天心情 —— 那是最难坚持的排期。

**所以规则反过来写:先有触发,再有图。**

### 五个触发位

| # | 触发 | 频率 | 展签写 | 情绪从哪来 |
|---|---|---|---|---|
| 1 | **周日的信**(封面) | 每周 1,**保底** | `LETTER NNN · 日期` | 信的主题 |
| 2 | **breadth 极值**(超买/超卖/动能翻转/趋势破位) | 行情给,0–2/周 | 当天测量 | 触发器直接给情绪 |
| 3 | **旧判断兑现**(赢和输都算) | 行情给 | `SAID … PAID … ±R` | 「判断被证明」/「止损」 |
| 4 | **月度节点**(月初) | 每月 1 | 当月 R / 胜率 | 复盘类 |
| 5 | **手痒** | ≤1/周,可跳过 | 当天测量 | 随便 |

**上限 3 张/周。下限 1 张(触发 1)。中间的空档就是空档 —— 没触发就不发,跳过不算欠账。**

这条跟蹭号回复的心法是同一条:*有测量就回,没有就不回。*

### 触发器

```bash
python3 scripts/poster_today.py        # 今天有没有理由
python3 scripts/poster_today.py --all  # 连没触发的规则也列出来
```

它读 `data/output/breadth.json`,输出:触发了什么 → 依据的数字 → 建议情绪 → 视觉库里对应的候选代码 → **拼好的测量行** → 可直接跑的 `make_poster` 命令。

没触发的时候它就说没触发。这是它最重要的功能。

### 默认阈值(可编辑,在 `scripts/poster_today.py` 顶部)

| 触发 | 条件 | 情绪 |
|---|---|---|
| 超卖极值 | T2108 < 20 或 >20SMA < 15% | 黑天鹅 → V17 V18 V22 / V50 V51 |
| 超买极值 | T2108 > 80 或 >20SMA > 85% | 系统失控 → V50 V51 |
| 动能翻转 | 5 日比 > 2.0 | 机会来了 → V45 V46 V48 V64 V65 |
| 动能塌陷 | 5 日比 < 0.4 | 混乱中保持冷静 → V10 V11 V23 |
| 趋势破位 | >200SMA < 40% | 等待 → V01 V03 V04 等 |
| 趋势修复 | >200SMA > 70% | 完全掌控 → V14 V31 V32 |

> 这些阈值是**默认值,不是回测出来的**。触发器只给数字和依据,发不发你定。
> 想改就改顶部的 `TRIGGERS` 列表,情绪关键词会自动去视觉库的索引表里查代码。

## 三、四周测试判据(沿用 Content Ops 第 7 节)

第 5 周你有没有**自己想**发第 5 条?
- 有 → 转正为固定栏目,信内加 toggle
- 没有 → 降级成手痒才发的彩蛋,**框和触发器留着**,它们零维护成本

**衡量的是 Substack 订阅,不是转赞评。** —— Quartr 报的也是下载量和订阅数,一个点赞数都没报。

## 四、版权

`visuals/candidates/` 是**筛选用毛坯**,来源是公开网络搜索,版权未核实,不入 git。
发布走三条路,按成本排:

1. **公有领域**(1928 年前的画 / 照片 / 老广告)—— 干净,气质也对
2. **AI 生成同题材** —— 情绪对了就够,不需要是本人。实测 V08「凌晨空训练馆」最好的候选就是生成图
3. **原图直发** —— 只用在明显评论性质的低风险场合,不做成固定栏目

第 2 条顺带解决了框的一致性:自己生成的图能按同一套光线和构图出,68 条能长成一个系列。
