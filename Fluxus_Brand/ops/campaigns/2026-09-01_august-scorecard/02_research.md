### 主张 2 · 派生量：Extended 拿走三分之二的笔数，却只拿回不到六成的 R

**复算方式（脚本输出 §B，算式随行）**：

**⚠️ 这里推翻 signal 节的一半框架。** signal 写的是「最该改的习惯赚了最多的钱……Extended 贡献 +28.7R / $137,857，是四档里最多的」——**绝对值上对，效率上完全相反**：

- Extended 占了 **66.67% 的笔数**，只拿回 **59.54% 的 R**、**57.83% 的钱**——它的份额是**被稀释的**，不是被放大的。

- 换句话说：**Extended 赚得最多，只是因为他在那里下注最多；每一次下注它是三个赚钱档里最差的那个。**

所以「胜率低不等于做错」这句 signal 的辩护**只成立一半**：它救得了 Extended 的绝对贡献，救不了它的单位效率。真正的中心主张应该是这个张力，不是那个辩护。

### 主张 4 · 仓位校准与 SQN 逐格无误，SQN 用报告自印的公式复算得 1.9419

**出处**：`monthly_2026-08.html` §「仓位大小」§「系统质量」

**复算方式（脚本输出 §E，用报告自己印出的公式）**：
`SQN = √min(N,100) × (meanR ÷ stdevR)`，`meanR = 48.2/42 = 1.1476R`（对上 Expectancy +1.1R），

报告原文对这条的自我限定（**必须随 SQN 一起出现**，一字不改）：

> Tharp grades a system by the consistency of its R-stream, not by return — raising it means tightening the loss tail, not betting bigger.

以及它自己解释了为什么 N 要封顶 100：`an uncapped √N inflates a long record into a band it hasn't earned`。**这句本身就是可发布素材**——它是一个「我给自己的度量加了一道闸」的票根。

### 主张 7 · 「三个累计数打架」不成立：是同一个账户的两个截止时点，我对到了 **0.012 pp**

**这是本站被点名必须解决的问题。结论：signal 节的「三处打架」第 3 条是误判。**

**读到的两条契约原文（`git show origin/main:data/reference/DATA_CONTRACTS.md`）**：

> **§十三 [2026-08-31]**：8 月样例:`data/portfolio/reviews/monthly_2026-08.html`(**+12.9% 至 8/28 收盘**;**dashboard +17.87% 是含 8/31 盘中**,两者 **7 月末锚点完全一致 +90.5%**)。

> **§七 [2026-08-31]**：Andy 定：仓位与交易数字「以 dashboard/Portfolio Tracker 为准」，不读 `data/output/trades/` …… 结论是**两边其实都对，是我按 ticker 而不按 lot 对账** …… 另：`Fluxus_Receipts`/PDF 版 recap 的 Portfolio 段可能滞后（08-28 那份没删已平的 SAIL），**对外引用一律以 tracker 现读为准**。…… 在场 5 名 8 笔，**RETURN 124.56%** · CASH 48.15% · 365 closed。

**对账（脚本输出 §D）**：用**第一手**的 7 月末权益 $1,905,255 作锚，代入 §十三 引的月回报 +17.87%：

```
1,905,255 × 1.1787 = 2,245,724
2,245,724 / 1,000,000 − 1 = +124.57%
vs §七 引的 tracker RETURN  124.56%      差 0.012 pp
```

**两个来自不同文档、不同人写的二手数字（+17.87% 与 124.56%），经由一个第一手锚点，对到了 0.012 pp。** 这不是巧合能给的精度。

**所以真相是两组，不是三个**：

| 截止时点 | 月回报 | 累计 | 权益 | 谁印的 |
|---|---|---|---|---|
| **2026-08-28 收盘**（8 笔在场持仓**未盯市**） | +12.9% | **+115.2%** | $2,151,613 | 月报（第一手已核） |
| **2026-08-31 盘中**（在场持仓**已盯市**） | +17.87% | **≈124.56%** | ≈$2,245,724 | dashboard / tracker（二手引文） |

**差的 ~9.4 pp ≈ $94,111，就是主张 5 里那 8 笔「Mark 是 —」的在场持仓被真正盯市之后的浮盈**（PLTR ×2、NOW ×2、HOOD ×2、ZETA、FIG；§七 提到 NOW 08-17 与 08-18 两笔当时分别在 6.5R / 3.6R）。**口径差，不是数据打架。**

#### 判断：Andy 的裁决**覆盖累计回报，不覆盖月报独有的聚合统计**

**依据三条，全部来自裁决行本身的文本**：

1. **裁决的主语是限定过的**：原句是「**仓位与交易数字**『以 dashboard/Portfolio Tracker 为准』」——不是「所有数字」。
2. **它替代的对象写明了**：「**不读 `data/output/trades/`**」。被替代的是逐笔 JSON 台账，不是月报聚合。
3. **紧跟其后的『权威读数』清单全是 tracker 字段**：逐笔 R（TEM/MRNA/NOW/SAIL/CRCL）、在场 5 名 8 笔、RETURN / CASH / 365 closed。**胜率、总 R、赔率、SQN、市场状态归因——tracker 里根本没有这些字段**，「以 tracker 为准」对它们**不可表达**。
4. 另外，「对外引用一律以 tracker 现读为准」这半句在原文里挂在「**`Fluxus_Receipts`/PDF 版 recap 的 Portfolio 段可能滞后**」之后，主语是**持仓段的时效性**。

→ **累计回报**：两边同名同物（tracker 有 RETURN 字段），裁决**咬得住** → 用 tracker。
→ **胜率 / 总 R / 赔率 / SQN / 归因表**：tracker 没有对应字段，裁决**够不着** → 只能用月报，但必须按主张 6 写全分母。

#### ⛔ 但「覆盖」≠「可以抄 124.56%」

裁决的字是「**现读**为准」。**124.56% 是 2026-08-31 的一次读数，被写进契约行的那一刻起，它就是二手数了。** 按宪法「数字只有一个家 · 永不转抄二手数」，转抄它去发布是违规的。

**对外可引用的写法（给旗舰站/Gate 的硬模板）**：

- **累计回报** → 发布当天**现读 tracker**，写成：
  `截至 <发布日> tracker 现读：累计 +X%（起始资金 $1,000,000，含在场持仓盯市）`
  **本卡不提供这个数——它必须在发布日现读。**
- **8 月这个月** → 可以引 **+12.9%**，但**必须带口径**：
  `+12.9%（截至 2026-08-28 收盘；8 笔在场持仓未盯市）`
  ⛔ 不可以把 +12.9% 当成「8 月的成绩」不加限定。**真实的 8 月（含 8/31 盘中盯市）约 +17.9%。**
  ⭐ 注意方向：**这个偏差对 Andy 有利——他实际赚得比这份报告显示的多。正因为对他有利，更要老实说，否则就是拿一个保守数字换可信度，赔了。**
- **归因表 / 胜率 / R / 赔率 / SQN** → 可引，分母按主张 6 写。

## 四、值得展开的机制（给 ③ 角度站的三个矿脉，按强度排序）

### 机制 A ⭐ **「份额被稀释」——低胜率的真实代价不在胜率上，在效率上**

这是**本卡唯一够格当中心主张的**（主张 2）。
Extended 拿走 **66.67% 的笔数**，只拿回 **59.54% 的 R**。三个赚钱的档里它的均 R **最低**（+1.02R vs +1.57R vs +3.37R）。
读者的可复用物是一个**拆法**，两步：
1. 胜率必须按**入场时的环境**分层看；
2. 分层之后，**别看总额，看「笔数占比 vs R 占比」的差**——那个差就是这个习惯真正的税。
配上警告 ②（按入场日归档）和第四条（n=3/5/6），这条既锋利又诚实。

### 机制 B ⭐ **「同一个月，两个真数」——口径而不是对错**

主张 7。+12.9% 和 ≈+17.9% 都对，差的只是「在场持仓盯不盯市」。
这条的价值在于它**同时是 BUILD 帖和判断帖**：一个自己给自己做复盘的人，会撞上「我这个月到底赚了多少」这个看起来不该有答案分歧的问题。
⭐ **而且答案对他不利的方向是保守的**——他实际赚得更多，报告显示得更少。**主动说出这一点，比任何自谦都更贵。**
可复用物：**任何一个回报数字，都必须带三个限定——起始资金、截止时点、在场持仓怎么算。** 三个缺一个，这个数就不可复查。

### 机制 C **「我给自己的度量加了一道闸」——SQN 的 N 封顶 100**

报告自印：`an uncapped √N inflates a long record into a band it hasn't earned`（主张 4）。
这是一个**极小、极具体、极难伪造**的诚实动作：他在自己的评分公式里，主动加了一个**只会让自己分数变低**的限制。
配上「SQN 1.94 = Below average，而这个月 +12.9%」这个反差（signal 节的打架 #2，**成立**——SQN 判 R 流一致性，不判回报，报告自己写明了），这是一条现成的短帖。
⚠️ 但注意：**这条和机制 A 抢中心位。** BRAIN §三「一个中心主张，不许两个」——建议 A 当旗舰，C 拆去分发站当独立入口。
