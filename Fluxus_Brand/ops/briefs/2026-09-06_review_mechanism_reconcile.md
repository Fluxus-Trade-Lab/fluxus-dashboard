## 二、缺口的本质：不是少一份文件，是少一个方向

现在的形状（每层独立，箭头全指向原始数据）：

```
原始数据 ──▶ daily-recap（每日 PDF）
原始数据 ──▶ build_month_doc（月报）
原始数据 ──▶ H1 Review（半年）
```

你要的形状（每层读下一层的产出）：

```
每笔思考 + tracker ──▶ 每日复盘 ──▶ 每周复盘 ──▶ 每月复盘 ──▶ 半年
                         (已有)      (缺)        (升级)      (已有模板)
```

**为什么方向决定一切：** 「以后我们会用的最好的交易是什么、错过的最好机会是什么」这类结论**只能从横跨多个单元的阅读里长出来**。周读五个日、月读四个周——模式才可见。每层从原始数据重算，永远只看得见那一层自己。
