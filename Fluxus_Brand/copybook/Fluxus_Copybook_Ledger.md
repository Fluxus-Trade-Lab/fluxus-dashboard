# Copybook 台账

*配套 `Fluxus_Brand/copybook/Fluxus_Copybook_Spec.md`。每日一段,每周日一次回顾。*

> **规矩 1:预测在用户表态之前写死,落账后不可修改。** 事后调整预测会让命中率这个指标一周内失效。
> 记错了就在原行后面补一句更正,**不改原文**。
>
> **规矩 2(2026-08-02 立):命中率只算用户的初判。** dispute 之后用户改判的,单独记一行,**不计入命中率**。
> 否则 Claude 有动机去 dispute 每一条没猜中的卡片,把指标做花。**dispute 是为了学判据,不是为了刷分。**

## 每日段模板

```
## YYYY-MM-DD(周X)
卡片 N · 存 a · 杀 b · 过 c
预测 #xx #xx #xx → **命中 m/3**
误判:#xx <我预测会存但被杀 / 我没预测但被存>,理由「<用户原话>」→ 命中/新增 <哪道闸>。修正:<下次预测怎么调>。
存:#xx @who 形态N · #xx @who 形态N
杀:#xx @who 形态N · #xx @who 形态N
```

**「误判」这一行是整个台账里唯一真正产生学习的部分。** 命中的那些不用写理由 —— 命中只说明我们已经重叠,不说明我学到了什么。

「存但没进 Swipe File」的,在该条后面标 `(存但未入库:装不进素材)`。

~~**我的假说:** 这条主张「别去解释价格」,而我们是「用算术解释」派,所以像同类、立场相反。~~
**❌ 假说错了。用户给的真实理由更有用:**

> 「price action 是最**显性**的,也是最后的结果。对于普通人来说这个是**没有 bias 的数据**。而另一种思考方式即 follow the whale,其实是从**动机**思考,从参与者的**意图**去思考,是博弈心理游戏。」

**→ 新判据(比我的假说根本):区分「显性数据」和「动机推断」。**

| | 是什么 | 例子 | 可测吗 |
|---|---|---|---|
| **显性数据** ✅ | 已经发生的、无 bias 的结果 | price action · **GEX** · breadth · 被迫抛售的量 | 可测 |
| **动机推断** ❌ | 猜参与者在想什么 | whale 在吸筹/派发 · 庄家意图 · 「聪明钱在布局」 | 只能猜 |

**分界线不是「数据 vs 故事」,是「被约束强制的行为 vs 自愿的选择」。**
Dealer 因为 gamma 必须对冲 → **强制的,所以可测**。Whale 想吸筹 → **自愿的,只能猜**。

⭐ **这条判据在品牌语言里早就存在了:「算法猴子」——*It never panics and it never gloats. It just obeys the code.*** 算法猴子之所以可测,正因为它是被代码强制的。这个隐喻本身就编码了这套认识论。

**cantonmeow 那条为什么落在错误的一侧:** 它用「price action 不需要被解释」(用户同意 —— PA 是数据)当引子,推向「impulsive moves 是 whale 干的」(用户不买 —— 那是动机推断)。**前半句对,后半句换了认识论。**
