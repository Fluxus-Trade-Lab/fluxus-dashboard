## 〇之二、口径先查过了，抄了谁

动手定标准之前先查有没有专业口径（`METRIC_SOURCES.md` 的规矩）。查到四份，本文件的分节直接照抄：

1. **过程**照 Arnott / Harvey / Markowitz《A Backtesting Protocol in the Era of Machine Learning》
   （*Journal of Financial Data Science*, Winter 2019）的**七点协议**：研究动机 · 多重检验与统计方法 ·
   数据与样本选择 · 交叉验证 · 模型动态 · 复杂度 · 研究文化。原文 PDF 已读
   （[Duke 版](https://people.duke.edu/~charvey/Research/Published_Papers/P138_A_backtesting_protocol.pdf) Exhibit 2）。
   我们的 P1–P7 是它那七点里适用于「一篇教学附录」的那部分，逐条注明对应项。
2. **多重检验的门槛**照 Harvey, Liu & Zhu（2016）*…and the Cross-Section of Expected Returns*,
   *RFS* 29(1)：数据挖掘普遍存在时，新因子的 t 门槛**不是 2.0，是 3.0 以上**。
3. **少簇的推断**照 Cameron & Miller《A Practitioner's Guide to Cluster-Robust Inference》
   （*JHR* 2015）：簇数少（文献里「少」从 <20 到 <50）时，聚类稳健标准误**过度拒绝、区间偏窄**，
   要用 wild cluster bootstrap；事件研究里事件日聚集的后果见 Kolari & Pynnönen（*RFS* 2010）：
   横截面相关只有 0.05，事件日聚集也足以把显著性严重推高。
4. **呈现**照 SEC Marketing Rule（2022-11 全面生效）对 hypothetical / backtested performance 的披露清单：
   **说明计算用的判据（criteria）· 说明所有假设（assumptions）· 显著位置写明模型业绩的固有限制、
   并说明它不代表真实交易 · 支撑材料留存可复查**。我们不是注册投资顾问，这里不是合规声明，
   是把一份公开、成文、专门管「把回测拿给别人看」的清单拿来当自查表。

**自造的两条，明写在这里**（口径表规矩：自造必须自报）：
- **自造 A · 图表密度下限**（R4）。查过没有行业口径管「一篇回测要几张图」——监管清单只管披露内容，
  不管图表数量。所以每节 ≥1 张、全篇 ≥4 张、四类图各 ≥1 张是**我们自己定的发行下限**，
  依据是附录 I 实际的样子（三张网格图 + 一张真实个例图 + 一个交互表）和 Andy 批它的那句原话。
- **自造 B · 「只许方向」的簇数分界取 20**（V2）。Cameron & Miller 给的是区间（<20 到 <50），
  我们取最宽松的那一端当硬闸：**独立事件簇 < 20 的结论，一律只许报方向、不许把幅度当事实**。
  取 20 不取 50 是为了不把所有事件类研究一刀切死，这个取点是自造的。

## 一、过程（P1–P7）

每条都是**做完能被第三方查出来的动作**，右列写怎么查。

| # | 判据 | 怎么查（复核员照这一列查） |
|---|---|---|
| **P1** | 有预注册块，commit 时间早于第一行计算。假设一句话、可证伪、**先有理由再有数**（AHM 1a/1b：事后编经济解释是红旗） | `git log` 看 prereg 文件的 commit 时间 vs 脚本首次 commit 时间 |
| **P2** | **池子是 point-in-time 全集**：当时在册的成分股全在里面，退市、被剔除、跌没了的一只不少（AHM 3a）。做不到时只有一条路：**声明偏差方向 + 结论降级为方向**（不给幅度、不给排名、不上结论表的百分比） | 池子清单的生成命令在不在脚本里；有没有退市票；报告里有没有「偏差往哪偏」那句 |
| **P3** | 规则跑前冻结：事件识别、分组、窗口、参数、剔除规则全部写在 prereg 里；跑后改动＝新一轮，`spec_search_n` +1（AHM 3c/3d：变换与剔除都算一次尝试，离群值不许随手删） | prereg 里的规则逐条对得上脚本；对不上的在报告里有「这条是跑后加的」 |
| **P4** | `spec_search_n` 如实累计并写进正文报数的那句话（AHM 2a/2c） | 数变体：识别口径 × 低点取法 × 分组法 × 尺子 × 窗口 × 剔除项，乘起来对不对得上台账里那个数 |
| **P5** | 一条命令可复算：脚本 + 结果台账 JSON + 数据来源与 hash/生成命令 + 固定 seed；**书里每个数都能指到台账里的一个键** | 照命令重跑一次，对头条三个数 |
| **P6** | 结论进 `data/research/claims/claims.jsonl`，`study` 字段指到书稿路径，状态诚实 | `python -m pipeline.tools.claim_registry --check` 绿；grep 书稿路径能在台账里找到 |
| **P7** | 数据质量与可执行性交代清楚（AHM 3b、4c）：复权口径、分红处理、幸存偏差、有没有计交易成本；**不含成本的读数必须写明「这是统计读数，不是交易结果」** | 报告里有这一段；正文里的措辞对得上 |

## 二、验证（V1–V7）

| # | 判据 | 怎么查 |
|---|---|---|
| **V1** | **基准同框**：每个正向结论旁边有一个无信息基准（随机入场 / 等权全池 / 指数自身 / 乱序对照），基准的数印在同一张表里。附录 I 的样板：随机入场持有 120 天利润因子 1.74，所有信号读数都拿它比 | 表里有没有基准行；有没有「比基准好多少」而不只是「涨了多少」 |
| **V2** | **每个头条数字带不确定性**：按**独立事件簇**（一次修正 / 一段行情 / 一只票，取最粗的那层）算区间，簇数少时用 wild cluster bootstrap，并写明「少簇下区间仍偏窄」。**簇数 < 20 ⇒ 只许方向、不许幅度**（自造 B）。同时报两个 n：观测数与簇数 | 报告里有 n_obs 与 n_clusters 两个数；每个头条数字后面有区间；簇数 < 20 时正文里找不到被当事实用的幅度 |
| **V3** | 观测不独立要**处理**，不是只承认：同票在多次事件里复用 ⇒ 按事件聚类或先按事件取平均再合计（Kolari & Pynnönen） | 脚本里有聚类/两步合计；p 值与区间用的是处理后的 n |
| **V4** | **三类敏感性各做一次，判据事前写死**：①识别口径（换一个定义）②参数（换窗口/阈值/取点）③样本（剔掉最极端的那一段行情）。通过＝方向相同 **且** 幅度不低于主结果的一半（协议 §四同一条尺子） | 三类都在；每类都报了主结论翻不翻；「幅度不低于一半」这句在 prereg 里而不是事后 |
| **V5** | **给幅度的结论要过 holdout**（另一段时间或另一批票，跑一次）。过不了就留 `candidate`，正文只许说方向。样本切不出 holdout ⇒ 说明池子太小，回到 P2 | 台账 `evidence.holdout` 非空；书稿里给幅度的句子对得上 validated 的那几条 |
| **V6** | **至少测一个替代解释**（混杂因子），分层与回归两种做法都给。附录 J 的 beta 分层是正样板 | 报告里有分层表 + 一个控制了该因子的回归；结论有没有因为控制它而消失 |
| **V7** | **同义反复自查**：判据和被解释量共享算术时（「跌得少所以离新高近」「先创新高的就是跌得最少的」），必须**量化扣除后再报**——按共享量分档或放进回归，报扣除后还剩多少 | 找到那对共享量；报告里有扣除后的数；正文的结论用的是扣除后那个 |

## 三、呈现（R1–R8）

Andy 那句「只有叙述性语言，而没有数据图表」指的是这一节。**这里的每一条都是发行前能数出来的。**

| # | 判据 | 怎么查 |
|---|---|---|
| **R1** | **每个主结论至少一张图，图承载结论本身**——读者不读文字也能从图上看出结论方向。装饰图不计数 | 逐节数图；每张图配一句「这张图说明什么」 |
| **R2** | 四类图各至少一张（自造 A）：①**分布图**（形状与尾部，说明「正常长什么样」）②**逐次/逐格点图带误差棒**（一致性与不确定性，几次成立几次不成立一眼看见）③**参数网格**（敏感性：换参数结论怎么动）④**一张真实个例图**（读者认形状用，附录 I 的 NVDA 那张） | 四类点名；缺哪类写明为什么这篇不需要 |
| **R3** | 每张图带：n（观测数与簇数）· 基准线 · 区间；轴定死不随数据跳，配色与标注照 `chart-for-andy` skill | 看图；轴范围与同篇其他图一致 |
| **R4** | **密度下限（自造 A）**：主结论节每节 ≥1 张图，全篇 ≥4 张；方法节与限制节不计入 | 数 `![` 的个数与所在节 |
| **R5** | 每张表有 **n 列**和**基准行**；比例后面跟计数（`84.3%（102/121）`），不给裸比例 | 看表头与单元格 |
| **R6** | **状态标签上页**：每条结论旁标 `validated` / `candidate` / `null`。**candidate 只许说方向**（「多数修正里更高」），**不许给幅度当事实**（「高 6.5 个百分点」）；`null` 照实说「测不出」，不许写成「似乎有」 | 逐条对台账状态；grep 书稿里的百分比，看它们挂在哪个状态下 |
| **R7** | **限制写在正文，不许只写在审稿批注里**：口径选择、偏差方向、样本量、不含成本——读者看不到的地方不算写过（SEC 清单的 criteria + assumptions + prominent limitations 三件） | 把「不进正文」的批注块遮住，正文还说不说得清这三件 |
| **R8** | 页脚一句可复算：脚本路径 + 台账路径 + 数据来源；发行版里保留 | 点进去文件在不在 |

**发行闸**：R1–R8 与 P1–P7、V1–V7 **缺一条即不发行**。缺的那条写明缺什么、什么时候补。
这不是「尽量做到」——附录 J 已经因为这一条被撤出发行版（书线 `c67e206`），先例在那里。

### 重做清单，两档，书线挑一档

## 五、状态标签怎么写进书

| 台账状态 | 书里允许的措辞 | 禁止 |
|---|---|---|
| `validated` / `live` | 给幅度、给百分比、给排名，带区间与 holdout 数 | — |
| `candidate` | 只给方向与逐次计数（「7 次里 6 次」）；数字出现在逐次表里，不做结论句 | 头条幅度、「平均高 X 个百分点」当事实 |
| `null` | 「测不出」「没有优势」，并给分辨率（能看见多大效应） | 「似乎有」「略有优势」这类把 null 写成弱正向的措辞 |
| 未登记 | 不发行 | — |
