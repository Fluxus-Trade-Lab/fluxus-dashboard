# Kerb 配对阶梯（XLY:WMT spread z）—— 规格与快测

*2026-09-02。源：@bcrossleypy id 2095007309042757808（"My fav kerb idea"，全文已入 turin_fixtures/tweets.jsonl）。kerb = @kerberos007，turin 的 VIX-TS 与 corr indy 同源。*

## 他的规格（原文机械化）

价差 = XLY:WMT（他注明 "$COST is better"），z-score 阶梯：
- **进**：z < −1 → 1/3 仓；z < −2 → 加到 2/3
- **出**：z > 0 → 出 1/3；z > +1 → 出 1/3；z > +2 → 尾仓 trailing
- **停**：z < −3 全出

⚠ 原文写 "long WMT & short h·XLV"——但止损在 −3（入场下方）、止盈在回升侧，阶梯只有**做多价差**（long XLY / short WMT，赌均值回归）才自洽；那行按他一贯的手滑处理，回测用自洽方向。h 未定义，本测按 log-ratio 1:1（美元中性近似）。z 窗口他未给，本测 252d（屋规默认）。

## 三条结论

1. **阶梯结构本身有正期望**（WMT 腿，28 年 78% 胜率）——分批进出 + 灾难停损的形制是真的，赚的是价差均值回归的小钱、防的是 2008/2020 型穿仓。
2. **他的 "$COST is better" 在我们测试里不成立**：COST 长期跑赢产生 log-ratio 的世代下行趋势，做多价差=常年逆势接刀。WMT 的比值更区间化，才是这套打法的宿主。（与 GEX/OAS 的教训同族：带趋势的序列不能当均值回归标的。）
3. **回填了 E1 的一个谜**：wmtxly3 当 SPX 择时切 NULL——因为这个量的信息在**价差自身的均值回归**里（相对价值域），不在指数尾部预测里。同一个量，择时机器废、配对机器活。

## 边界

我们不做配对交易执行（calc engine, not advice）——本档只存规格与验证。未测参数：z 窗口敏感性、beta 对冲版 h、交易成本/借券费；trailing 简化为 z>+2 即出。模拟器初版有「止损死循环」bug（停后立即重进），已修——止损类回测必须带冷却，记入方法注意。
