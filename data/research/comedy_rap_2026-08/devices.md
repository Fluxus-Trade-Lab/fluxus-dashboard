## 一、压缩族（目标 A）—— 主要来自喜剧

### `device-01` · 重写词放最后
| | |
|---|---|
| **机制** | 一句话的最后一个词，回头改写前面所有词的意思 |
| **动作** | 写完一句，问「哪个词是转折点」——**把它移到句末**。如果转折点在中间，读者在读到它之后还要走一段冗余 |
| **交易写作用在哪** | 「我看到什么」那一行；任何「你以为是 X，其实是 Y」的判断 |
| **Andy 已有的样本** | *"I do treat the market like a video game. **The difference is my respawns cost real money.**"* — 转折词在最后 |
| **怎么证伪** | 把转折词往前挪，读一遍。若毫无差别，这条 device 在这句上不成立 |
| **状态** | A/B待判（C1、C3） |

### `device-02` · 具体名词替类别词
| | |
|---|---|
| **机制** | 具体的东西比它的类别**更短且更快被看见**——「甜点」比「表现分化」少三个字且立刻成像 |
| **动作** | 每出现一个抽象名词（轮动/宽度/情绪/延伸），问「它在现实里长什么样」，用那个东西替掉它 |
| **交易写作用在哪** | 所有内部术语的出口（Voice Bible §4.8 第 5 条「方法论词汇不上台面」的**执行方法**） |
| **Andy 已有的样本** | *"a fish breaks the surface"* 替掉了「信号触发」；*"chop-fest dessert"* 替掉了整段宽度读数 |
| **怎么证伪** | 具体化之后词数没降、或画面需要一句解释才成立 → 失败（这时它是**装饰**不是内容） |
| **状态** | A/B待判（C1、C2、C6） |

### `device-03` · 砍连接词
| | |
|---|---|
| **机制** | 并置本身就暗示因果。`because` / `so` / `which means` / `and therefore` 是在替读者做一件他会自己做的事 |
| **动作** | 通读，删掉每一个逻辑连接词，改成句号。**读不懂的地方再加回去**——加回去的那几个是真需要的 |
| **交易写作用在哪** | 全篇；这是**词数下降最快**的一条，本轮 A/B 里 5 组用到它 |
| **示例（交易语境）** | 「群体一个月没有绿数，**所以**我的钱在错的地方」→「那个群体一个月没有绿数。我的钱在那儿。」 |
| **怎么证伪** | 删完之后出现歧义（读者会读出第二种因果）→ 这里的连接词是承重的，加回去 |
| **状态** | A/B待判（C1、C2、C5、T2、S1） |

### `device-04` · 反高潮
| | |
|---|---|
| **机制** | 把张力堆到顶，然后用一个**平的短句**落地。落差本身是内容 |
| **动作** | 高潮句之后**不要解释**，直接接一个 ≤7 词的陈述句，且这句不许带形容词 |
| **交易写作用在哪** | 亏损那天那一句；「代价」栏；自嘲 |
| **Andy 已有的样本** | *"It touched nearly 200 that afternoon. **I was asleep.**"* — 这是全篇最好的反高潮，已在用 |
| **怎么证伪** | 落地句里如果出现「其实/不过/但是」，它就不是反高潮，是解释 |
| **状态** | A/B待判（C1、C4、S7） |

### `device-05` · 前提当事实陈述
| | |
|---|---|
| **机制** | 把一个观点写成一句观察，读者自己完成「这是个判断」这一步。deadpan 的语法基础 |
| **动作** | 删掉所有 `I think` / `in my view` / `it seems` / `arguably`。**留下的那句如果不敢说，说明它本来就不该写** |
| **交易写作用在哪** | 「盘面」和「所以」两行（`templates/daily_post.md` 定的**冷行**）——冷不是没有技法，冷就是这条 device |
| **Andy 已有的样本** | *"Even in hard times, people smoke."*（讲防守股）· *"The tape does not care whether I am watching it."* |
| **怎么证伪** | 删掉限定词之后你不敢发 → 这句话缺的不是修辞，是证据 |
| **状态** | 未测（本轮盲选里没有单独测它的位） |

### `device-15` · 画面替数据 —— ⚠️ **本轮找到了它的边界**
| | |
|---|---|
| **机制** | Voice Bible §4.8 第 3 条已经定了这条。本研究要补的是**它什么时候不成立** |
| **动作** | 替换前先问一句：**这个数字是修饰，还是证据？** 修饰的替掉；**证据的不能替，只能挪**（挪进 LEDGER 行 / 括号 / 图注） |
| **实测边界** | C6 是唯一一组**在 expository 类里没过 −30% 线的**（9%）。病因不是画面不好，是那段的两个宽度数字**是「规则到期了」这个判断的证据**——把它们换成画面，省下的词全部来自**删证据**，不是来自压缩 |
| **由此改写的一句规矩** | 「比喻优先于数据」→ **「比喻优先于当修饰用的数据。当证据用的数据不参与比喻，它换个位置。」** |
| **怎么证伪** | 替换后读者仍能追问「凭什么」而文中无处可答 → 你刚才删的是证据 |
| **状态** | 实测（C6 的 9% 是脚本算的，不是我判的） |

## 二、落地族（目标 B）—— 主要来自说唱

### `device-11` · 重音收尾
| | |
|---|---|
| **机制** | 英文句子的**最后一个重读音节**是读者记住的位置。收口落在弱读音节上=话说完了但没落地 |
| **动作** | 收口句的最后一个词：**≤2 音节、重音在首、具体名词或动词**。禁止落在 `-tion` / `-ity` / `-ing` / 介词 / 代词上 |
| **交易写作用在哪** | 每一节的最后一句；X 帖的最后一行 |
| **对照（Andy 自己的）** | *"…nothing left for him to **press**."* 落在 press（单音节动词）✅ ／ 若写成 *"…nothing left for him to press the **button** with."* 就散了 |
| **怎么证伪** | 把收口念出来，最后一个词若可以拖长而不难受 → 它是弱收尾 |
| **状态** | A/B待判（S1、S2、S3、S8、S10） |

### `device-08` · 内韵 —— ⚠️ **只偷这个韵，不偷句尾韵**
| | |
|---|---|
| **机制** | 元音在**行内**重复，让句子好记；一旦落到两行的**行尾**，英文散文立刻变打油诗 |
| **动作** | 允许：同一句里 2–3 个词共享元音（`bound the pain` / `cost / lost`）。**禁止**：相邻两句以押韵词结尾 |
| **交易写作用在哪** | 想让某一句被复述时（定位句、refrain） |
| **示例（交易语境）** | 「**Bound** the pain and you stop shopping for signal.」——`bound/ou` 与 `shopping/o` 在行内呼应，行尾是 signal（不押） |
| **怎么证伪** | 把两句的**末词**抄出来单看：若它们押韵 → 违规，改写 |
| **状态** | A/B待判（C4） |

### `device-07` · 硬停顿
| | |
|---|---|
| **机制** | 在语法只要求逗号的地方放句号。读者被迫停一拍，那一拍就是重音 |
| **动作** | 一段里**最多用一次**。用在你最想让人停的那个词后面 |
| **示例（交易语境）** | 「Confused? Take risk off.」——问号造出的停顿把两个动作切开 |
| **怎么证伪** | 一段里出现两次以上 → 节奏变碎，读起来像喘 |
| **状态** | A/B待判（T1、S2） |

### `device-09` · 一词双义
| | |
|---|---|
| **机制** | 一个词同时干两件事（字面 + 交易语境），一行因此承载两行的信息。**Jay-Z 那一格的核心** |
| **动作** | 找交易语境里本来就有两层的词：`position`（仓位/位置）· `cover`（回补/掩护）· `carry`（持仓成本/扛着你）· `paper`（纸面/头寸） |
| **Andy 已有的样本** | *"everyone underneath is **carrying** you"* — carry 同时是「持有」和「扛着」 |
| **怎么证伪** | 若读者只会读出一层，它就是个普通词；**双关不成立时不许硬留**（那是炫技） |
| **状态** | A/B待判（C5） |

### `device-06` · 自我引述（把自己拆成两个人）
| | |
|---|---|
| **机制** | 用句法（不是嗓音）标出「另一个我」在说话，把心理写成人物 |
| **动作** | 给那个人一个动作，不要给他形容词：**「the frightened version of me sits down」** ✅ ／「我当时很恐惧」❌ |
| **交易写作用在哪** | 所有讲纪律的段落——这是**把说教变成场景**的唯一便宜办法 |
| **Andy 已有的样本** | *"when the frightened version of me sits down there's nothing left for him to press"* — 已经在用，且是全篇最强的一句 |
| **怎么证伪** | 那个「另一个我」若没有动作、没有位置 → 他不是人物，是形容词 |
| **状态** | A/B待判（C3） |

### `device-13` · tag（补一刀）
| | |
|---|---|
| **机制** | 在一个已经落地的句子后面，**不新起铺垫**，直接再补一句更短的。第二刀吃的是第一刀的势能，成本为零 |
| **动作** | 只在**已经成立**的句子后面加；tag 必须比前一句短，且**不引入任何新信息** |
| **示例（交易语境）** | 「It's the most expensive thing on the menu. **And it isn't food.**」 |
| **怎么证伪** | tag 里出现新名词/新数字 → 那不是 tag，那是下一段 |
| **状态** | A/B待判（S4、S7） |

### `device-14` · callback
| | |
|---|---|
| **机制** | 后文复用前文的画面，**一个词提走一整段**。这是全库压缩率最高的一条，但需要前文先付款 |
| **动作** | 前文立一个具体画面 → 中间隔至少两段 → 后文只提那个词，不解释 |
| **配套硬线** | Voice Bible §4.8 第 4 条：**比喻要连成一条链，换喻体=破功** |
| **示例（交易语境）** | 前文「a fish breaks the surface」→ 后文只写「that one surfaced on the 14th」 |
| **怎么证伪** | 读者需要往回翻才懂 → 隔太远或画面立得不够硬 |
| **状态** | A/B待判（S5） |

### `device-12` · 憋住不给释放
| | |
|---|---|
| **机制** | 该给笑点/该给安慰的位置**不给**，让张力留在读者身上 |
| **动作** | 写到最疼的地方，**不写「但是」那一段**。段落到此结束 |
| **交易写作用在哪** | 亏损那一天；17 连亏；39.9% 胜率——**Andy 的可信度正来自这里** |
| **⚠️ 界限** | 它和「卖惨」只差一件事：**有没有把代价写成数字**。有数字=证词，没数字=人设（`templates/daily_post.md` 的界限②） |
| **怎么证伪** | 如果段末忍不住加了一句宽慰或转折 → 释放给出去了，这条没用上 |
| **状态** | 未测 |

### `device-10` · 清单体反高潮
| | |
|---|---|
| **机制** | 两项建立模式，第三项破坏它（rule of three）。**破坏项必须是最短的那个** |
| **动作** | 三项，前两项同构同长，第三项换语域且更短 |
| **⚠️ 冷热分区** | **不许用在「盘面」和「所以」两行**——那两行的清单是读数，不是节奏（`templates/daily_post.md`）。见 `null_results.md` NULL-4 |
| **示例（交易语境）** | 「Two-week money. Ten-month money. Same price.」 |
| **怎么证伪** | 第三项若比前两项长 → 模式没被打破，只是列了三件事 |
| **状态** | A/B待判（S2、S8、S9） |
