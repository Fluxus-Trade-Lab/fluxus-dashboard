## 1. 数据与它的偏差（先写清楚，因为它决定怎么读结果）

- `.cache/stock_panel.pkl`：**只有收盘价**，2016-08-08 → 2026-08-07，2,514 场 × 3,025 列（含 SPY），`auto_adjust`，`ffill`。
- 票池 = **今天**（2026-08）市值 ≥ $3 亿、日成交额 ≥ $200 万的票（`pipeline/themes/backtest_accel.py:eligible_tickers`）。
- ⚠️ **幸存者偏差，而且方向对 LanceB 有利**：十年里跌到退市、或跌到 $3 亿以下的票，一只都不在池子里。
  暴跌之后「最后没活下来」的那批被整批删掉了，剩下的暴跌大多是后来反弹了的。**跌得越深，这个偏差越大。**
- 所以本轮的读法**不对称**（写死）：
  - 若叠加变量**没有**改善中位 → 这是在对它有利的偏差下仍然没改善，**NULL 可信**。
  - 若叠加变量**改善了**中位 → **不能**当成 LanceB 对了，只能写「和幸存者偏差分不开」。
  - 这正是为什么主检验要**按跌幅深度分层**（§4）：深度是偏差的主要载体。
- 只有收盘价，所以**十个变量里只能测四个**（§3）。成交量（他说越来越看重的那个 #5）**测不了**。

## 2. 事件（base 池）

- ticker-day 满足 `C_t / C_{t-5} − 1 ≤ −10%` 且 `C_t ≥ $5`。**（自造的「急跌」入口；LanceB 的前提是 in-play，没有可照抄的数值口径。）**
- 去重：每只票触发后 10 个交易日内不再计入（取第一天）。
- 需要 `t+5` 存在（前瞻窗口完整）。
- 只做**抄底方向**（他的框架两边都做；只有做多方向与我们归档一致，摸顶留空）。

## 3. 四个可测变量（得分 k = 0..4）

| # | LanceB 的变量 | 本轮口径 | 出处 |
|---|---|---|---|
| V1 | Acceleration（加速，「asymptote」） | `L3 / L10 ≥ 0.6` 且 `L10 < 0`，其中 `L3 = ln(C_t/C_{t-3})`、`L10 = ln(C_t/C_{t-10})`——最后 3 天走完 10 天跌幅的 ≥60%（匀速是 30%） | **自造**。查过无标准口径；阈值 0.6 = 匀速的 2 倍 |
| V2 | Multiple days in the same direction（「三天或更多」） | 连续 ≥3 个收盘下跌：`C_t < C_{t-1} < C_{t-2} < C_{t-3}` | 他本人的数「three or more days」 |
| V3 | Extreme Bollinger Band extension | `%B < 0`：`%B = (C − Lower)/(Upper − Lower)`，BB(20, 2)，SMA20 ± 2×总体标准差 | ChartSchool %B Indicator，默认 (20,2)；「below zero when price moves below the lower band」 |
| V8 | Extreme market sentiment | 当日池内收盘高于自身 SMA50 的比例 `< 30%` | ChartSchool Percent Above Moving Average：「readings below 30% are deemed oversold」。⚠️ **偏离**：标准挂在指数成分上，我们挂在自家池子上（与 `METRIC_SOURCES` 09-11 那条同一个偏离） |

**测不了的六个，明写**：#4 不接新鲜消息（没有新闻数据）· #5 成交量暴增（面板只有收盘价）· #6 多段同向 · #7 极少整理 · #9 越无聊越好 · #10 市场结构放大。
→ 本轮结果**只对这四个变量说话**，不对「LanceB 的清单」整体说话。

## 4. 结果变量与检验

- **主结果**：`x5 = C_{t+5}/C_t − SPY_{t+5}/SPY_t`（信号日收盘进，5 日后收盘出，相对 SPY 超额）。
- **次结果**（「right side of the V」的日线近似）：信号日后 3 天内出现第一个上涨收盘才进，进场后 5 个交易日收盘出；3 天内没有上涨收盘 = 不进场（单独计数）。
- 每个 k 档报：n · 中位 · 均值 · 胜率 · `P(x5 ≥ +10%)` · `P(x5 ≤ −10%)`。

**两个点名假设（×2 校正，α = 0.025 每个）**：

- **H-L（LanceB）**：叠得越多，中位越好。
  统计量 = **按深度分层后**的 `median(k≥3) − median(k≤1)`，三层 `r5 ∈ (−15%, −10%] / (−25%, −15%] / ≤ −25%`，按层内事件数加权。
  置信区间 = **按 ISO 周整簇 bootstrap**（事件在崩盘周高度扎堆，不能按事件抽），2,000 次，取 95% 双侧区间；**下界 > 0 ⇔ 单侧 α=0.025**，正好是 0.05 做 ×2 校正后的每假设水平。
- **H-M（Muninn）**：叠得越多，右尾越肥，中位不动。
  统计量 = 同样分层加权的 `P(x5≥+10% | k≥3) − P(x5≥+10% | k≤1)`，同样的簇 bootstrap。
  「中位不动」＝ H-L 的区间含 0。

**判定规则（写死）**：
- H-L 在 discovery 与 holdout **都**区间下界 > 0 → 「中位改善，但与幸存者偏差分不开」（见 §1，不写成 LanceB 对了）。
- H-L 区间含 0 或 < 0 → NULL（在有利偏差下仍无改善，可信）。
- H-M 同理，两臂都 > 0 才算复制。

## 偏离记录（看结果之前写；只动了安慰剂，没动任何判定规则）

**D1 · 安慰剂的置换范围（2026-09-12 05:4x JST）。** §6 写的是「同一周、同一深度层内置换 k」。首跑 100 次：
中位差的周簇区间排除 0 的比例 **0%**，右尾差 **100%**，点估计全部落在同一侧。这不是 5%，按 §6 先修检验。
**原因**：周内置换保留了「k≥3 的事件落在哪些周」，而 V8 是按日期的变量，崩盘周的事件天然 k 高——
所以那个置换不是本统计量的零假设，它是「只剩市场择时、个股层信息清空」的对照。
**改为**：只在深度层内、跨全部日期置换 k（k 与周完全脱钩）。重跑 100 次（每次 300 次 bootstrap）：
区间排除 0 的比例 中位 **2%** / 右尾 **3%**（目标 5%，略保守），点估计均值 ≈0。
→ 分辨率：中位差的置换 95% 带约 ±0.14%，右尾差约 ±0.48pp；小于这个的效应本检验看不见。
**周内置换的那份保留**（`placebo_discovery_week.json`，脚本 `--placebo-scope week`），在 results.md 里**明标事后**，
只用来回答「效应有多少来自市场层（哪几周）、多少来自个股层」，不参与判定。

**D2 · 两只票的复权价为负**（CBIO、DEC，共 2,273 格）。`ln` 在那里给 NaN → V1 记 False；这些格的价格也过不了 `C_t ≥ $5`。不剔除，照记。

⚠️ **D1 的诚实披露**：周内置换那份的点估计（中位差均值 ≈ −0.20%、右尾差均值 ≈ −2.3pp）是**结果变量的一部分信息**——
它告诉我「k≥3 的事件所在的那些周」本身右尾更瘦。这是我在跑主结果之前**已经看到的**东西。判定规则没因此改动。
