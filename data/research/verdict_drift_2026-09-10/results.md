## 一、先说两把尺子怎么失败的（这一节比结果重要）

我先造了两个便宜的检测器，两个都不能用，而**失败的方式不一样**：

### 尺子 A：「脚本比裁决旧」——它对已知阳性一次都报不出来

想法是：裁决写在 md 里、脚本没跟着改 ⇒ 脚本的最后修改时间 < 裁决的写入时间。
实测 21 个目录**全部报「同日」**。查到底：09-09 那颗炸弹里，
`results.md` 的裁决句和 `review_benchmarked.py` 是**同一个 commit** `1e9090e8`（09-01 05:10）进仓的。

```
$ git log -S'SPY 是错的尺子' --format='%cI %h' -- .../results.md
2026-09-01T05:10:16+09:00 1e9090e8
$ git log --format='%cI %h' -- .../review_benchmarked.py | tail -1
2026-09-01T05:10:16+09:00 1e9090e8      ← 同一个 commit
```

**裁决和被它推翻的工具是一起出生的，不是一个比另一个旧。**
一个人在一晚之内既写出「这个分母是错的」，又交付了一个用那个分母的脚本——
时间戳这把尺子在这种形状上永远读到 0。**先验证它能报出阳性，才轮到信它的阴性。**

### 尺子 B：关键词——召回未知，而且低

段落级扫「是错的 / 不该用 / 正确的做法是 / 已证伪 …」+ 同段出现 `.py` 路径：
**8 条命中，真裁决 2 条**。若就此收工，我会写出「扫完了，只有 1 个」——
而实际是 4 条漏网 + 27 条已标死。
按 [[pitfall_a_handwritten_whitelist_measures_my_vocabulary]]：**手写白名单量的是我的词汇量。**
裁决在这个仓库里多半写成一句自我更正（「我第一版把这一栏写成……那是错的」），不是命令句。

**所以这件事没有便宜的机械检测法**，它要求读懂文档和代码在说同一个量。
本轮改用 fan-out：7 批 × 3 目录，每批读完全部 md + py，
每条候选再派**两个不同视角**的复核（证据链 / 替被告辩护），默认倾向推翻。
共 39 个 agent，51 个脚本 / 48 份文档全读，无抽样。

## 三、被推翻的十条里，有两条是复核比扫描更对

**这是本轮 fan-out 值它成本的地方**，记下来给下次设计复核用：

1. **`delayed_ep_review_2026-09/label_permutation.py`**（扫描判 high/high，复核 2/2 推翻，**我自己复核后同意推翻**）：
   它确实写着 `BENCH = "SPY"`，看起来是同一场事故的第三个漏网。但它的零假设是
   **「标签在同一场内可交换」**——检验的是「`breaking` 和同日同池的随机抽样比」，
   而 SPY 在同一场内是个常数，**在场内置换里直接抵消**。
   > **同一个 token 出现在两个脚本里，不代表它在两个脚本里担同一个角色。**
2. **`pipeline/screeners/watchlist.py`**（扫描判「08-27 至今一字未改、没有任何标记指向那份研究」，复核 2/2 推翻）：
   标记在，只是不在被点名的那两行上——`watchlist.py:50` 写着
   `# (claims.jsonl: oratnek-width-adr-floor / …)`，顺着走到 `claims.jsonl:29`，
   那条 claim 的 `updated` 就是那轮研究当晚，`gates` 字段直接点名 `MIN_ADR_PCT=3.5`。
   **本仓已经有把「代码闸 ↔ 研究裁决」绑在一起的机制**，而我差点把它报成缺失。

## 四、机制：已经有的那一半，和缺的那一半

`data/research/claims/claims.jsonl` + `pipeline/tools/claim_registry.py`（CI 里跑 `--check`）
是本仓现成的绑定机制：33 条 claim，**16 条带 `gates`**（「这条结论在哪里改变了行为」），31 条 `study` 指向 `data/research/`。
`gates` 非空而 status 没到 validated/live/null 就红，waiver 到期也红——09-08 那次 C_gate 拦红就是它。

**它绑的是「结论 → 生产代码里的闸」。它不绑「裁决 → 产出这个结论的分析脚本」。**
而今晚这 4 条全部住在后者。

**提案（不是规矩，我不改宪法）**：
一份研究档推翻了某个方法，**同一个 commit 里**要么改掉实现它的脚本、要么在脚本里标死；
并且标死的粒度是**每条裁决一行**，不是每个文件一段——
因为今晚 4 条里有 3 条，文件上已经有横幅了。

**代价**：一句话。**不做的代价**：09-09 一整夜的结论推倒重来，而踩它的是写那条裁决的同一个人。
