# 预注册 —— Delayed EP：第几天入场？

**写于 2026-08-26 05:0x JST，跑第一行计算之前。** 依 [`RESEARCH_PROTOCOL.md`](../../reference/RESEARCH_PROTOCOL.md) §二。

## 0. 为什么测这个

08-25 的视频转录（[`stockbee_2026-08/method_video.md`](../stockbee_2026-08/method_video.md) §六）
抓到我们自己实现里的一处**实质出入**，不是「他没说」而是「我们做的和他说的不一样」：

| | 我们 `delayed_ep_scan.py` | 他（视频原话） |
|---|---|---|
| 入场窗口 | `--min-days 3 --max-days 15` | 「second day entry was very good」[01:32](https://www.youtube.com/watch?v=Rm9f2E-mygM&t=92s)<br>「sometimes the best entry is **on the next day**」[03:09](https://www.youtube.com/watch?v=Rm9f2E-mygM&t=189s) |

**我们的默认值 `--min-days 3` 恰好排掉了他反复强调的那一天。** 这条已作为 S8 建议给了 DATA ALEX，
但**建议本身没有证据**——没人量过第 1、2 天到底比第 3–15 天好还是差。本轮就量这一个东西。

⚠️ 本轮**不动 `pipeline/tools/` 任何文件**（EP 链归 DATA ALEX）。产出是数字与建议，不是代码改动。

## 1. 假设（各自可证伪）

- **H1（他的主张）** —— 早入场更好：`D ∈ {1,2}` 的超额收益**优于** `D ∈ {3..15}`。
- **H2（我们默认值的代价）** —— `--min-days 3` 排掉的那两天（D=1,2）**不劣于** D=3。
  H2 是 H1 的弱化版：即使 D=1,2 没有优势，只要不劣，我们的默认值也在**无谓地丢机会**。
- **H3（他的窗口 vs 我们发明的尾巴）** —— `D ∈ {1..4}`（他给过例子的区间）
  **优于** `D ∈ {5..15}`（他从未展示过、我们自己延伸出来的区间）。

**先验**：三条都**低**。理由：本仓库自家回测的正向结论按协议 §六是 D 级证据；
且 08-24/08-25 连续两轮闸研究的结论形状都是「中位不动」（[[project_b4_gates_null]]、
[`amplitude_2026-08/results.md`](../amplitude_2026-08/results.md)）。**默认预期是三条全 NULL。**

## 2. 度量（提前钉死，跑完不改）

- **事件**：`data/history/ticker_events.csv` 中 `screener == 'episodic_pivot'`。
  498 行 / 407 只 / **97 个不同 EP 日**，2026-03-09 .. 2026-08-21。
- **价格**：yfinance 日线，`auto_adjust=False`。**只用到 last completed session = 2026-08-24 收盘**
  （ET 现在 08-25 15:32，盘中，08-25 那根不完整，一律丢弃）。
- **入场**：EP 日之后第 D 个交易日的**收盘**，D ∈ {1..15}。
- **持有**：固定 5 个交易日。
- **超额**：`excess(D) = (C[D+5]/C[D] − 1) − (SPY[D+5]/SPY[D] − 1)`，SPY 同窗。
- **主检验（配对，事件内）** —— 每个事件贡献一条 D 曲线，所以**配对**而不是两组独立样本：
  - **P1（H2）**：`mean_excess(D∈{1,2}) − excess(D=3)`，逐事件配对差，Wilcoxon 符号秩，双尾。
  - **P2（H3）**：`mean_excess(D∈{1..4}) − mean_excess(D∈{5..15})`，同上。
  - **P3（H1）**：`mean_excess(D∈{1,2}) − mean_excess(D∈{3..15})`，同上。
- **描述量**：每个 D 的 `median excess` / `>0 占比` / `n`，画成一条曲线（这条曲线才是给人看的结论）。
- **显著性门槛**：`p < 0.05`。三条主检验做 **Holm 校正**（family = 3）。

## 3. Holdout（先划再跑）

**按 ticker 哈希 50/50 分半**，salt = `dep-window-20260826`：
`int(sha1(salt + ticker).hexdigest(), 16) % 2 == 0` → discovery，否则 holdout。

- 选 ticker 哈希**不选时间切分**的理由：首轮复盘（[`../delayed_ep_review_2026-08/README.md`](../delayed_ep_review_2026-08/README.md)）
  的头号问题就是「整份日志只有一个市场窗口」。按时间切会让两半各自落在不同行情里，
  把「窗口效应」和「切分」混在一起。按名字切，**两半的日历完全相同**。
- **discovery 上判 H1/H2/H3，holdout 只报复制**（符号 + 量级 + p），**不重调任何参数**。
- ⚠️ **弱污染声明**：我在写本预注册前已经查过这批事件的 `change_pct` 分布与日期直方图
  （498 行 / min +10.0% / 97 个日期），但**没有看过任何前瞻收益**。度量和分半都写死在动价格数据之前。

## 4. Kill criterion（提前写好，免得事后找补）

- 完整拿到 D=1..15 全部 bar 的事件 **< 150** → 判**样本不足**，只报描述曲线，**不下任何结论**。
- 任一 D 的有效 n < 100 → 该 D 的点在图上标灰，不进检验。

## 5. 本轮**测不了**的（先写下来，免得结论被过度引用）

1. **他的主边是做空，我们测的是他的附注。** 视频原话「especially in this video i'm going to focus on
   **short side**」。而我们归档里 498 个 EP 事件 **`change_pct` 全为正**（最小 +10.0%）——
   我们的 EP 筛子结构上只记向上跳空。**他那套「财报 miss → 跳空低开 → 反弹 2–4 天 → 破位做空」
   在我们现有归档上根本无法测量**，不是没测，是没有数据。
2. **入场口径不是他的。** 他从不收盘入场（「enter in the first five, ten or twenty minutes」），
   理由是止损距离。我们全部以收盘计。这是口径差异不是参数差异。
3. **一个行情。** 2026-03..08 六个月、一个上行为主的年份。
4. **重叠窗口。** 同一事件的不同 D 高度相关——这正是选配对检验的原因，但**跨事件**的
   日历重叠仍在（同一天有多个 EP），所以 p 值是**上界**，真实的更不显著。
5. **零成本假设。** 不含滑点、手续费、借券成本。

## 6. 预登记的解读规则

- 三条**全 NULL** = 「第几天入场在我们的口径下无差别」→ 那么 `--min-days` 的默认值
  **不是收益问题而是覆盖问题**：改到 1 只是多几个候选，不是变好。
- **只有 H2 成立**（D=1,2 不劣） = 默认值在**无谓丢机会**，建议改 `--min-days 1`。
- **H1 或 H3 成立** = 我们自己发明的 5–15 天尾巴是负担，建议同时收 `--max-days`。
- **反向显著**（早入场明显更差）= 我们的默认值**歪打正着**，S8 建议应当**撤回**，并在
  `open_questions.md` 里改成「已实测，别改」。
