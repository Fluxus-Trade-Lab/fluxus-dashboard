## 一、答案：能。而且已经复刻出来了

原帖：[@RealJGBanks 2026-09-09](https://x.com/RealJGBanks/status/2097845762293944348)（收藏 56 / 赞 69）。
他给了两个数：**1950 年起，中期选举后 12 个月标普 19 战 19 全正，均涨约 15%**；
**中期选举后的 11 月到次年 6 月，21 战 21 全正，均 +16.6%**。

数据够：`yfinance` 的 `^GSPC` 实测能回到 **1940-01-02**（21,793 个交易日）——比他要的 1950 还早十年。
选举日是规则算出来的（11 月第一个星期一之后的第一个星期二），不需要外部日历。

## 三、⭐ 复刻过程里掉出来的一件事

他一条帖里报了 **19 战 19** 和 **21 战 21** 两个战绩，开头写的是「自 1950 年起」。

**1950 到 2022 只有 19 次中期选举。** 要凑到 21 次，起点得退到 **1942**。
也就是说，他第二个数悄悄换了起点，而帖子里只写了一次「Since 1950」。

不是造假——两个窗口在 1942 起算都是全正，数本身站得住（上表两行都验过）。
但**同一条帖里的两个计数不共享起点**，读者会以为是同一个样本的两种切法。

这正是我们能补的那一格：他给结论，我们给**这个结论在什么口径下成立、换个口径还成不成立**。

## 四、留给 Linda 的三个坑（我没做，只标出来）

1. **口径先查再造**（宪法 08-31 条）。「中期选举年周期」是 *Stock Trader's Almanac* 的标准题目，
   窗口定义（选举日锚点 vs 10 月底锚点 vs 年度锚点）业内早有写法。**动手前先找那个写法，别自己发明第三种。**
2. **n=19 是 19 次选举，不是 19 个独立观测。** 相邻周期共享宏观状态，重叠度要量。
   先算这个检验的最小可能 p（宪法坑账 `pitfall_compute_the_minimum_possible_p_first`）——
   19 次全正的符号检验单边 p 是 2^-19，看着极显著，但**「全正」这个统计量是事后选的**：
   在 21 个可选起点 × 若干个可选窗口里挑出全正的那一格，就是 p-hacking。要跑排列检验。
3. **1940 之前有没有？** 我只测到 yfinance 的边界，**那是 yfinance 的边界，不是世界的边界**
   （坑账 `pitfall_longest_available_is_a_claim`）。Shiller 的月度数据回到 1871，免费。

## 五、复刻脚本

```python
import yfinance as yf, pandas as pd, datetime as dt
df = yf.download('^GSPC', start='1940-01-01', end='2026-09-10', progress=False, auto_adjust=False)
c  = df['Close']; c = c[c.columns[0]] if hasattr(c, 'columns') else c
c  = c.dropna()

def px(d):                       # 当日或之后第一个交易日的收盘
    s = c[c.index >= pd.Timestamp(d)]
    return (s.index[0].date(), float(s.iloc[0])) if len(s) else None

def elec(y):                     # 11 月第一个星期一之后的星期二
    d = dt.date(y, 11, 1)
    while d.weekday() != 0: d += dt.timedelta(1)
    return d + dt.timedelta(1)

for y in range(1942, 2024, 4):   # 中期选举年
    e  = elec(y)
    p0, p1 = px(e), px(dt.date(y+1, e.month, e.day))
    q0, q1 = px(dt.date(y, 10, 31)), px(dt.date(y+1, 6, 30))
    print(y, f'{(p1[1]/p0[1]-1)*100:+.1f}%', f'{(q1[1]/q0[1]-1)*100:+.1f}%')
```
