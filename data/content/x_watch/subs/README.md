### ⚠️ kind / proxy 判断规则(09-17,取件账 09-17·2)

- **`kind` 不能用正则扫全文**——`Focus` 这个词会出现在正文中间(教学帖标题里也带「Focus」),正则首词匹配会把非 Focus 帖也判成 Focus。**以首行第一个词为准**,不是全文搜索命中。
- **代理票 `via` 写法可能跨行**(`$BE` 换行 `via` 换行 `$BEX`),先把换行压成空格再跑 `via` 匹配,否则会漏判代理票。
- 拿不准就人工判,别硬套正则出错数。
