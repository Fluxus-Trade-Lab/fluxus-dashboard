# The vendor-facing pins are exact on purpose. yfinance owns the crumb/cookie
# handshake with Yahoo and its behaviour has changed across minor releases;
# with an open upper bound, every night's CI install was an uncontrolled
# input -- "which client did we use last night" had no answer in the repo.
# 1.7.0 is the version that ran the successful nights of 2026-09-01..09-03
# (runs 33477559153, 33571359007, 33597360358, 33695423921), so it is the
# version we know works against Yahoo today.
#
# To bump: change the pin, run the nightly by hand once (workflow_dispatch,
# outside 09:30-16:15 ET), and only keep the new version if that run lands
# data. Never bump blind -- a client-side handshake change looks exactly like
# a throttle from the log side.
yfinance==1.7.0
